# 需求 · 案例标签筛选 · 2026-10-09

## 需求描述

为已有 550 个案例增加可点击的中文分类标签，按标签找到相关案例。

## 背景 / 原因

现有图片、视频、网站三大类较宽，案例增多后，仅靠关键词搜索不方便浏览同类用途与题材。

## 用户故事

员工想学习某种作品的做法，例如食品广告或个人作品集，需要直接选择标签，再阅读对应案例的方法与完整提示词。

## 验收标准

- 全库按“用途”和“题材”整理，区别于来源作者标签；原文、作者与原始出处保持。
- 两组可组合，也可与三大分类及关键词搜索组合；点击卡片或详情标签可以查找同类。
- 显示匹配数量，能取消单组或全部清除；零结果有明确恢复入口。
- 连续预览、详情前后、返回列表和刷新保留完整筛选条件。
- 桌面标签可用键盘操作，手机提供紧凑筛选；构建和针对性测试通过。

## 范围

先整理用途和题材，不扩展为无限自由标签、标签编辑后台或生成工具评级。标签不是效果复现证明。
