# 测试报告 · 项目内容与功能优化 · 2026-10-09

本轮优化的发布版本为 v1.74。工作汇报课程及配套材料、参考答案、下载包和进度功能已按验收意见取消；其余优化获准发布。本报告记录本地验证范围，正式网站在发布后单独核验。

## 本轮交付

- 重写四篇核心内容，修订办公与工具教程、PPT 历史评测说明、正文互链和部分概念表述。共涉及十三篇已有文章。复核日期只在已复核范围内展示。
- 精编十三个代表案例的准备材料、步骤、变量与检查标准；四百个详情页都明确区分来源作品、作者原提示词、本站步骤及练习，并显示未实测生成效果。原文、来源、署名、媒体、验证状态和顺序保持。
- 十三条视频补适合人群、材料和练习；主导航共用清单，手机搜索可用；案例支持多关键词组合搜索；视频弹窗支持键盘操作及焦点恢复。
- 词汇本支持备份预览、同名去重合并、请求中断恢复、单次超时与取消等待，并同步主站主题。静态页移除明文口令，访问配置与主站共用。
- 能力自测补充上下文与任务验收的学习推荐，说明报告在当前浏览器计算和保存。新增学习事件只发送固定动作和类别。
- 构建入口和发布脚本纳入测试、案例检查、站内资源和锚点检查；日报首页跳转采用 VitePress 实际生成的锚点。

## 测试环境

- 桌面端：macOS，Codex 内置浏览器。未将这次结果视为独立 Chrome、Safari 和 Windows 验收。
- 移动端：浏览器 390 × 844 响应式视口；未使用真实手机或微信内置浏览器。
- 页面验收：本地开发预览及完整构建后的静态预览；预览入口为 `http://127.0.0.1:5178/`。
- 本地 Node：v22.22.2。未执行远端 Node 20 GitHub Actions，线上验证需要发布后完成。
- 统一检查：`npm run docs:check`，包含 39 项自动测试、生产构建、400 个案例与 617 个 HTML 页面链接检查。

## 发现的问题

- 首页一条日报的手写锚点与正文不同，已采用 VitePress 实际解析结果，补充历史与格式回归。
- 部分案例练习使用通用建议且来源边界不明显，已精编十三条，其余保留并明确标为本站建议。原提示词没有补写时长或音轨。
- 香氛案例曾将画面要求当成工具输出规格，以及从橄榄画面推断香调；已改为作者画面要求、实际输出待核对和橄榄植物画面。
- 词汇页含明文访问口令、无备份恢复且中断记录可能停留在等待状态，相关展示与状态处理已修复。
- 兼容范围内修复依赖后，完整依赖审计由 8 项降到 3 项（1 高、2 中）；生产依赖审计为 0。剩余项在 VitePress 1.x 的 Vite/esbuild 开发构建链，需要另作升级兼容评估。本轮未强行升级主框架。
- 构建仍有部分代码包大于 500 kB 的提示。构建成功；本轮没有取得真实访问性能数据，不以此直接作框架迁移或拆包结论。

## 遗留风险与后续验收

- 访问口令没有轮换。原口令曾以明文存在公开静态资源，去除现有明文不能收回历史副本；需由维护者另行设置新口令。当前前端密码门仍是阅读入口控制，不能作为真实敏感公司资料的保密措施。
- 未在 Safari、真实手机、微信、Windows 和远端 Node 20 构建环境验收；发布后需验证正式域名与深层链接的授权/未授权路径。
- 没有在生成工具中复现 400 个案例或这十三条精编案例，没有重新生成 PPT、复测视频中的工具或购买订阅。旧 PPT 内容明确保留历史评测边界。
- 词汇本“停止等待”会取消前端请求，不保证服务端生成或计费已经停止；页面已提示，不能据此认定没有费用。
- 新增事件是动作次数：案例下载事件表示点击下载，自测完成表示走完作答流程；均不证明下载成功、作品达标、节省工时或独立完成。需要真实读者提供作品与核对记录后，才能评估学习效果。
- 十三条精编是首批试点；剩余 387 条没有逐条重新设计练习，已明确其通用建议的本站来源。后续可依据读者使用情况扩充精编范围。
- 模型排行榜与视频原记录具有时间边界。页面显示同步/整理说明；并未把旧播放量或收藏量包装为实时数据。
- 最终正式发布仍按项目验收与 publish.sh 流程执行。本次没有改域名、部署配置或素材库，也没有删除已入库资料。
