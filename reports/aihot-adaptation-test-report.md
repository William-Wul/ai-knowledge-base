## 发现的问题及处理

- 排行榜旧 CSS 类名已不存在：改为表头语义定位，校验仍保留。

- 日报自动任务最近 8 天成功，但旧脚本漏掉概述与快讯，10/05 来源无精选时出现空白正文：已补齐。
- 旧 API 宣布 10/31 停用：迁移 v1，适配 report 与来源链接字段。
- 旧日报脚本允许部分成功后回写，可能回退到旧一期：改为所有期数抓取校验完再写入。
- 桌面模型列过窄：已调整列宽并允许名称换行。

## 遗留风险

- 上游再次改动字段或结构仍可能触发失败保护；任务不会用异常内容覆盖已有数据。
