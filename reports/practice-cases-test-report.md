## 发现并修复的问题

- 原版使用独立 page 布局，未复用网站侧栏；案例样式也未稳定进入生产页面加载链。现改为原生 docs 布局，样式由主题全局加载，增加构建资源检查。
- 返回链接丢失搜索条件，改为保存明确的分类路径和查询，而非读取跳转中的地址。
- 全站默认按空格分词，中文关键词无法命中；构建与浏览器共用中文分词并回归旧文章搜索。
- 列表/详情切换会触发 VitePress 目录组件卸载后的滚动回调。列表改为关闭目录内容并隐藏侧栏区域，保持原生组件稳定挂载。
- 短提示词不再无条件渐隐；长内容可展开，复制始终取全文。
- 来源动作图实际为作者操作截图，已准确标注；工具案例明确是选文件组件，不宣称包含上传后端。

## 遗留风险

- 手机为 Chrome 窄屏模拟，未覆盖真实 iPhone Safari 或微信内置浏览器。
- 远程视频仍依赖来源媒体服务；失败时保留方法和完整提示词可用。
- 首批案例尚未在对应生成模型中复现，内部记录保留；文案分类等待符合条件的来源案例。
