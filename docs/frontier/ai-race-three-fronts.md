# 后训练、Harness、价格战，AI竞赛的三条战线

**2026 年 8 月 12 日深夜到 8 月 14 日，短短 72 小时，AI 圈接连发生了三波大新闻：**

- **8 月 12 日深夜**，有开发者发现 DeepSeek 官方文档悄悄挂出了新模型 V4 Pro 的价格页——等了一个半月的"正式版"要来了；
- **8 月 13 日**，DeepSeek 一天双发：V4 Pro 正式版上线，同时开源了自己的 Agent 框架产品 **DeepSeek Harness**——就是 Codex、Claude Code 这一类东西：套在模型外面、让模型真正干活的那层"壳"；
- **8 月 14 日中午**，智谱发布 GLM-5.3：参数一个没动，官方称整体能力提升约 50%；同一天，"DeepSeek 涨价 12 倍""海外大模型反攻"的讨论刷了屏。

单看每一条，都像常规的发布新闻。但把它们摆到同一张桌上看，会发现这 72 小时其实意味着：**AI 竞赛同时开了三条战线——后训练、Harness、价格战**。这三条战线还有一个共同点：决定胜负的东西，越来越多地不在"模型本身"里。

一条条来。

---

## 战线一：大脑没换，手艺暴涨

先看 8 月 14 日的 GLM-5.3。它最"反常"的地方写在发布信息第一行：**基座模型与上一代 GLM-5.2 完全相同**——7400 多亿参数，一个没加，一处没改。但成绩单是这样的：

| 评测项（测什么） | GLM-5.2 | GLM-5.3 |
|---|---|---|
| Terminal-Bench 3.0（在真实电脑终端里完成复杂任务） | 4.6 | 28.3 |
| DeepSWE v1.1（长程软件工程，持续改代码） | 46.2 | 66.9 |
| Agents' Last Exam（跨工具协作的长任务） | 23.8 | 28.5 |

![GLM-5.3 官方基准总览](/images/frontier/ai-race-three-fronts/glm-bench-overview.png)
<p class="figcaption">GLM-5.3 官方基准总览：在 Terminal-Bench 3.0、DeepSWE、Agents' Last Exam 等六项上与 GLM-5.2、Kimi K3、Fable 5、GPT-5.6 Sol 的对比。（图源：智谱官方，量子位报道引用）</p>

参数没变，分数翻了几倍，钱花哪儿了？答案是**后训练**。

模型的训练分两大步。第一步叫**预训练**：让模型吞下海量文本和代码，学会语言、常识和推理。这一步决定能力的**底子**，也最烧钱——几万张显卡、几个月时间。第二步叫**后训练**：在底子之上，教模型具体怎么干活——怎么理解任务、怎么调用工具、怎么把一件事从头做到尾不出错。可以这么类比：预训练是运动员的身体天赋，后训练是训练方法。**博尔特的底子再好，也得练起跑技术和交接棒；底子一克不变，把手艺练精，成绩照样能涨一大截。**

据报道，这次智谱在"训练方法"上动了三样器材：IndexShare 让模型内部相邻的层共享一套索引，长文本处理省下的算力拿去练更长的任务；SAO 把"全班等最慢学生"的同步训练改成单条任务各自更新；Slime 把出题和练题两套系统解耦，流水线化。名字记不住没关系，记住方向就行：**算力和金钱，正在从"堆参数"转向"磨手艺"。**

手艺磨精了，最直观的体现是"会过日子"。在智谱自家的 Code Bench 高难度档，GLM-5.3 准确率 31.4%，超过了 Claude Opus 4.8 最高档的 29.5%；更关键的是，它平均每个任务只输出约 5 万 token，而 Opus 4.8 要约 12 万——**同样的活，干得又准又省。**

![Z.ai Code Bench 评测](/images/frontier/ai-race-three-fronts/glm-codebench-tokens.png)
<p class="figcaption">Z.ai Code Bench 评测：横轴是平均每任务输出的 token 数，纵轴是准确率。左上角是理想位置——又准又省。（图源：智谱官方，cxuanAI 报道引用）</p>

这次发布还有个出圈的插曲：安全能力。有媒体实测让它审计一个预埋了 12 类漏洞的代码库，它不只找出漏洞、完成修复，还主动补上了回归测试，作者独立重跑后 54 项测试全部通过；标题里最抢眼球的说法是"揪出潜伏 40 年的世界级漏洞"。对这类说法要保持一点清醒：漏洞细节和数量以官方披露为准，第三方分项数据也显示它在"发现漏洞"上很强、在"深度利用漏洞"上仍落后顶级闭源模型。但方向是明确的——模型开始被当成交付工程成果、能自我验收的一方来训练。官方称模型权重将在约两周内开源，之前要先做安全加固：限制攻击性用途，保留防御价值。

把镜头摇回 DeepSeek，会发现同一个剧本已经演过一轮：4 月底 V4 首发，旗舰 Pro 加轻量 Flash 双版本，靠架构创新把长文本成本打了下来；7 月底 Flash 正式版上线，公告明说"仅重新进行了后训练"，多项 Agent 指标反超自家旗舰；8 月 13 日，等了一个半月的 V4 Pro 正式版兑现，把这个路线坐实到旗舰上。**两家公司、同一周、同一个选择——这不是巧合，是行业重心的转移。**

## 战线二：模型之外的那一层，叫 Harness

8 月 13 日开源的 DeepSeek Harness，是这批新闻里最容易被普通读者划过去、其实最值得看懂的一个。先说它是什么：**Codex、Claude Code 这些 AI 编程产品，拆开看都是"模型 + 一层壳"——模型负责想，壳负责把想法变成动作**：能用哪些工具、按什么流程走、干过的每一步记不记录，都是壳在管。DeepSeek Harness 就是把这个壳单独拿出来做成的开源产品，跟 Codex、Claude Code 属于同一类东西，只是敞开程度更彻底。

多说一句"Agent"这个词。Agent（智能体）和聊天机器人的区别在于：聊天机器人只会回话，你问一句它答一句；Agent 能自己调用工具、分好几步执行、中途根据结果调整做法，更像一个你派出去办事的人。而一个 Agent 真正干活时，模型只是其中一部分——外面这层壳，行业起了个专门的名字，叫 **Harness**（直译是"马具"或"安全带"，可以理解为给模型套上的整套工作装备）。

![Agent = Model + Harness](/images/frontier/ai-race-three-fronts/agent-equals-model-harness.png)
<p class="figcaption">Agent = 模型 + Harness：模型是 Agent 的"灵魂"，Harness 负责让它理解环境、使用工具、在真实场景中持续工作。（图源：数字生命卡兹克）</p>

用职场类比最好懂：**模型是你招来的那个人，Harness是公司给他配的一切**——工位、电脑、流程制度、能用哪些工具、什么操作要审批、干的每件事有没有留痕。同一个人，扔进一家啥都没有的皮包公司，和进一家制度齐全的公司，产出天差地别。

这不是比喻，是有实测的。有媒体做了一个很说明问题的对比：**同一个 V4 Flash 模型，分别放进 DeepSeek Harness、Reasonix、Codex 三个不同的"壳"里，做同一个 3D 网页任务，产出差异明显**。也就是说，你在不同产品里感觉"同一个模型忽好忽坏"，很多时候不是模型的问题，是壳的问题——这是选 AI 工具时一个全新的判断维度。

DeepSeek 给这个壳定的规矩可以浓缩成一句话：**一切皆插件**。模型、工具、技能、会话、存储、沙箱、子 Agent、界面——全部做成可插拔的插件，通过配置组合，不必改源码。出厂还带了四种预设模式，像相机的场景模式：标准模式管日常；"极简"模式把附加能力全拆掉，专门测模型裸奔的真实水平；"PTC"模式让模型把读文件、搜索、批量调用等一串动作写成一段程序一次跑完，减少来回请示；最激进的是"创造"模式，允许 Agent 检查并改造自己的插件环境——给自己装装备。

![一切皆插件](/images/frontier/ai-race-three-fronts/everything-is-plugin.png)
<p class="figcaption">"一切皆插件，运行有迹可循"：模型、工具、技能、会话、沙箱、存储都以插件形式存在，通过配置层选择、替换和扩展。（图源：数字生命卡兹克）</p>

另一个设计值得单独讲：**全程留痕**。Agent 干的每一步——收到什么指令、调了什么工具、返回什么结果、派了哪个子 Agent——都按"只追加"的方式记进日志，像行车记录仪加工位周报，出问题可以逐帧回放。有媒体实测用翻译 88 页 PDF 论文的任务：主 Agent 发现任务太大，自动派出 10 个子 Agent 分头翻译再合并，22 分钟交货，全过程在轨迹视图里可以逐步检查。

![DeepSeek Harness 轨迹视图](/images/frontier/ai-race-three-fronts/session-trace-view.png)
<p class="figcaption">DeepSeek Harness 的轨迹视图：用户指令、上下文注入、工具调用逐条留痕，可检索、可回放。图为翻译 88 页论文任务的实际轨迹。（图源：智东西）</p>

要说清边界：目前开源的 v0.1 是开发者预览版，术语多、配置多，更像给开发者攒 Agent 的底层框架，不是给普通用户的成品。但看懂它的意义不需要会用它：**DeepSeek 是一家模型公司，却把重磅发布的位置给了一个"不是模型"的东西——这说明下一程竞争的胜负手，至少有一部分挪到了模型外面。**

## 战线三：价格战翻转，海外反攻

第三条战线最刺激，因为它打碎了一个两年攒下的印象：**国产模型一定便宜。**

先看 DeepSeek 这边。V4 Pro 正式版的价格是每百万 token 输入 3 元、输出 6 元（缓存命中 0.025 元）。单独看没感觉？对比此前一代的价格，这是**涨价 12 倍**；有媒体按峰谷时段和实际用量结构算过，部分场景下已经比 GPT-5.6 Luna 还贵。曾经的"价格屠夫"，把屠刀先架在了自己的定价表上。

涨价本身不一定错——旗舰档收旗舰价，是商业上说得通的事。真正麻烦的是**证据打架**：官方 Agent 基准图上，V4 Pro 部分指标超过 Opus 4.8、个别超过 Fable 5；但第三方评测机构 Artificial Analysis 当天的综合能力分，只比自家轻量的 V4 Flash 高 1 分。中间还夹着一段插曲：社区发现其开源仓库里挂出的配置文件与 V4 Flash 高度相似，仓库随后调整，是否传错版本已无从确认。**同一款模型，官方考场和第三方考场给出了两种答案**——遇到这种情况，正确反应不是选边站，而是三样都看：官方基准是厂商挑过题的考场，第三方榜单是统一卷子但口径不同，真实价格还分峰谷时段。

![模型市场性价比分布](/images/frontier/ai-race-three-fronts/cost-intelligence-map.jpg)
<p class="figcaption">以"任务成本"为横轴、"智能指数"为纵轴的模型市场分布：左上角的"斩杀区"聚集着又便宜又强的模型（DeepSeek V4 Flash、GPT-5.6 Luna 等）。"比谁便宜"的战况，在这张图上一眼可见。（图源：Artificial Analysis，AI范儿报道引用）</p>

DeepSeek 让出的空档，海外厂商立刻踩了进来。**Gemini 3.7 Flash** 被评测者定位为"又快又便宜的编程/Agent 模型"：综合能力指数已经逼近甚至超过部分旗舰，价格还是限时优惠价。**Grok 4.6** 的信号主要在 Agent 维度：在 Artificial Analysis 的 Agentic Index 上，它与 Claude Opus 5 以 59 分并列第一梯队，而价格显著低于同档闭源模型。

![Agentic Index 榜单](/images/frontier/ai-race-three-fronts/agentic-index.png)
<p class="figcaption">Artificial Analysis 的 Agentic Index 时点榜单：Grok 4.6（高推理档）与 Claude Opus 5 以 59 分并列第一。（图源：Artificial Analysis，AI范儿报道引用）</p>

这条战线的落点很简单：**"国产模型一定便宜"的旧印象，这一周正式作废**。往后比价，至少要看三件事——两边能力档位有没有对齐、是不是有一边在峰谷时段里挑了对自己有利的数字、便宜的那家是不是限时优惠。

三件事拼成一句话：**预训练定底子，后训练定手艺，外壳定下限，价格定普及——四件事里，只有第一件发生在"模型本身"里。**

对普通读者，有三个可以直接带走的判断：

    <b>② 同一个模型在不同产品里表现不一样，可能是壳的问题。</b>挑 AI 工具时，"用的什么模型"只是问题的一半，"模型外面套了什么"是另一半。<br><br>
    <b>③ 比价格别只看一个数字。</b>对齐能力档位、看清峰谷时段、问清优惠期限。榜单和跑分是初筛工具，不是终点。
