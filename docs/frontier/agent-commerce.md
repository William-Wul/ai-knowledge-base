# 未来商业形态探讨：当 Agent 成为消费者

过去几年讨论 AI agent，几乎都在讨论它"能替你做什么"——回邮件、写代码、查资料。

2026 年 5 月初的 Stripe Sessions 大会，把讨论推到了下一格：**agent 不只是替你做事，它正在成为一种新的"买家"。**

这不是 PPT 上的展望。Sam Altman 在主舞台直接打开 ChatGPT，输入"为这次会议买衣服"，由 OpenAI 的 OpenClaw 全程完成搜索、比较、选品、结算——人没离开聊天窗口，钱已经付出去了。

如果买家变了，整个商业基础设施都要跟着变。这篇文章梳理这场变化里，几件已经在发生的事。

---

## 一、AI 经济不是预测，是已经能在数据里看见的事

Stripe 处理全球 GDP 接近 2% 的交易量，年支付总额 1.9 万亿美元，服务超过 500 万家企业。Forbes AI 50 榜单里，86% 的公司都在用 Stripe 收款。

这给了它一个独特的视角——AI 经济到底在不在长大，它一眼能看见。

几个值得记的数字：

- AI 公司贡献给 Stripe 网络的年化收入，从 2024 年的约 40 亿美元，涨到 2025 年的约 440 亿美元。一年 10 倍。
- 把 AI 公司 Top 100 和上一代 SaaS 公司 Top 100 放在创业同等阶段比较，前者的增速大约是后者的 10 倍。
- 单位经济（人均年化收入）大约是上一代 SaaS 公司的 3 倍。
- 8 个月内年化收入突破 1 亿美元的 AI 公司，2025 年有 6 家——历史上极少出现。

经济学家罗伯特·索洛在 1987 年留下过一句话："你到处都能看到计算机时代，就是在生产率统计数据里看不到。"这句话困扰了经济学界将近十年。

Stripe 的视角让 2026 年的 AI 没有重复这个困扰——AI 对经济的影响，已经能在支付数据里看清。

---

## 二、AI 公司"第一天就全球化"

上一代 SaaS 公司从产品上线到走出本土市场，普遍要 2 到 5 年。AI 公司不是。

很多 AI 产品上线第一周，就同时收到来自巴西、印度、东南亚、日韩用户的付费。Stripe 的数据显示，**非美国市场近一半的支付走稳定币**——拉美的美元紧缺、印度跨境合规复杂、东南亚没有统一银行体系，过去这些都是出海公司绕不过去的摩擦。

稳定币把这些摩擦绕过去了：不用开本地银行账户，用户在自己的钱包里完成兑换，开发者第二天看到收入到账。

这是为什么"day 1 全球化"在 AI 时代第一次成为常态。

---

## 三、Agent 既是买家，也开始是卖家

Stripe Sessions 现场放了两个 Demo，组合起来才是完整的故事。

**第一个，agent 替人买。** 就是开头说的那个——Altman 在 ChatGPT 输入一句"为会议买衣服"，OpenClaw 完成搜索、比对、选购、结算。

**第二个，agent 替人卖。** 演示者用 ChatGPT 制作了一份装饰用的 SVG 图片，挂到一个 agent 商品市场上；另一位用户的 agent 在执行任务时自主发现了这张图、判断符合需求、直接下单买走，钱进入创作者账户。

把两个 Demo 拼起来，一个新结构就浮现了：

> 一边的人通过 agent 买东西，另一边的人通过 agent 卖东西，**中间没有传统电商页面，也没有传统结账流程**。

这不是替代某个具体的电商，这是在替代"电商"这种形态本身。

---

## 四、微支付为什么这次能跑通

按使用量微小金额计费（micropayments），是被讨论了二十多年的商业模式。每次都没跑通，原因是同一个——**人类做不了过细的消费决策**。

没有人愿意每按一次播放键就判断这首歌值不值 1 毛 5。所以 Spotify 用每月 9.99 美元订阅替代了按曲付费。

Agent 没有这种认知负担。

Stripe 旗下的 Tempo 区块链 + Metronome 实时计量引擎，在现场演示了"流式支付"：一个 AI 应用按消耗的 token 实时收费（每百万 token 3 美元），左边仪表盘显示 token 用量上升，右边稳定币微支付同步入账。打开 Tempo 浏览器，**一笔 3.30 美元的总额是由数千笔"1 美分的 1/3000"组成的**。

信用卡做不到，ACH 做不到，UPI 和 Pix 也做不到——这些渠道的单笔成本本身就比一笔微支付的金额还大。

如果 Stripe 的判断成立，意味着过去因为人类认知摩擦无法运转的整个商业模式品类，在 agent 面前可能突然变得可行。这不是"做小一点的支付"，这是"被 agent 唤醒的一整个商业模式品类"。

---

## 五、商家要做的最大改变：从"取悦人"到"取悦 agent"

Stripe 产品负责人 Jeff Weinstein 给出过一个判断框架：把 agent 想成你认识的最优秀的程序员。

人类消费者喜欢漂亮图片、流畅动画、有故事的品牌；agent 想要的是结构化数据、精确物流信息、用最少步骤完成交易的能力。

Meta 产品副总裁 Ginger Baker 把这种变化概括得更彻底：**支付将从一个"时刻"变成一个"策略"。**

人类购买是离散一刻：走到收银台、掏出钱包、刷卡、完成。

Agent 消费是连续策略：用户预设一组规则——"这周食品最多花 50 美元""始终优先用这张卡""500 美元以上不许自动授权"——agent 在授权框架内持续地、自主地消费。

商家面对的问题不再是"如何在结账瞬间打动人"，而是"如何被 agent 选进可调用商户池里"。这是两套完全不同的产品逻辑。

---

## 六、安全：算力是新的现金

新的买家必然带来新的欺诈方式。

Stripe 数据负责人 Emily Glassberg Sands 在大会上列了三种正在快速增长的 AI 公司欺诈：

| 类型 | 含义 | 数据 |
|---|---|---|
| 多账号滥用 | 同一个人反复注册不同账号薅免费额度 | AI 公司每 6 个注册有 1 个涉及滥用 |
| 免费试用恶意消耗 | 大量试用账号烧推理成本但不转化 | 某公司 25 次试用 → 1 次付费、19 次欺诈，单付费客户 token 成本 >500 美元 |
| 吃霸王餐 | 大量推理后月底拒付 | 直接对应"算力被偷走 = 钱被偷走" |

传统 SaaS 被滥用，成本几乎为零（只是占用一些数据库空间）。AI 公司的每一次推理调用都是真实的电费、GPU 租金、API 成本——**算力是新的现金**。

很多 AI 公司的第一反应是关掉免费试用层。但 Jeff 提醒了一件反方向的事：**agent 正在成为发现新服务的主要方式**。如果 agent 没法自己注册试用，它会直接跳到下一个 URL，根本不会"加入等候名单"或"联系销售"。为防欺诈关掉自助注册，等于把最重要的增长渠道送给竞争对手。

Stripe 给的解法不是"关闸门"，是**共享反欺诈网络**。Radar 把 500 万家企业的交易数据汇成一个共享的风险识别网络——一家公司遇过的欺诈模式，所有公司都受益。上个月，Radar 在 8 家高速增长的 AI 公司中拦截了超过 330 万次高风险免费试用注册。

更有意思的是 Jeff 抛出的一个反常识结论：**agent 购物可能比人类网页购物更安全**。人类网页购物的信任靠"猜测"——用户停留多久、点击路径正不正常。Agent 交易可以被程序化认证：原始信用卡号被 token 化、生物识别授权、单笔上限、时间窗口、商户白名单。当信任机制从"猜测"变成"确认"，安全水位反而可能提高。

---

## 七、协议层正在被抢位

这件事不是 Stripe 一家能做成的，需要整个生态共建。Sessions 大会上同时推动了三个协议：

| 协议 | 主导 / 参与方 | 解决什么 |
|---|---|---|
| **MPP**（Machine Payments Protocol） | Stripe | 让 agent 通过 HTTP 发现并完成支付 |
| **Agentic Commerce Suite** | Stripe + Google + Meta + OpenAI + Microsoft | 让消费者在各家 AI 应用内直接完成购买 |
| **UCP**（Universal Commerce Protocol） | Shopify 发起，Meta / Amazon / Salesforce / Microsoft 共建，Stripe 进总委员会 | 跨平台商业协议，避免 agent 被困在某一家生态 |

一群互为竞争对手的公司同意在共享协议上协作，原因很简单：**碎片化让 agent 难以在不同平台间顺畅消费，对所有人都没好处。**

这一段在历史上有过类似情节。1960 年代末，美国银行的 BankAmericard 信用卡向全国扩张，几十家互为竞争对手的银行需要共享基础设施，但找不到合适的组织形式。Visa 创始人 Dee Hock 用去中心化的设计原则解决了这件事，让所有银行成为新组织的平等成员，美国银行放弃了对系统的独家控制。

那个组织后来改名叫 Visa。

而今天 Stripe 推出的 Tempo 区块链验证节点列表里，其中一个名字就是 Visa——**学生搭了新网络，老师成了网络里的一个节点**。

---

## 八、对普通人意味着什么

把上面这些拼起来，三件事比较确定：

1. **下一波"哪个产品好用"会越来越多由 agent 而不是由人类决定**——它会基于结构化数据和履约稳定性来选择，不被 UI 漂亮度或品牌广告影响。
2. **个人和家庭的预算管理方式会变**——不再是"我去某个 App 看本月花了多少钱"，而是"我对 agent 设定一组消费规则，agent 在规则内持续支出并定期汇报"。
3. **被讨论了二十年没跑通的微支付商业模式会真正出现**——按使用量、按 token、按调用次数计费的服务将成为常态，订阅制不再是默认答案。

这些不会一夜之间发生。但 Stripe Sessions 2026 的现场展示已经说明，技术、协议、生态联盟都已经就位——剩下的只是产品落地的时间。

对普通用户，最值得做的一件事是：**意识到下次你买一件东西，决策者可能是你委托的 agent，而不是你自己。** 提前理解这件事，比等它发生再适应更从容。
