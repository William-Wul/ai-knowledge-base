## 开始前准备

准备准确的概念材料。Transformer 是许多语言模型使用的结构，能让模型结合上下文处理信息；原文要求通俗与细节兼顾，没有指定时长、声音或画幅。

## 怎么做

以下步骤与练习由本站整理，供学习时参考；作者原文保留在下方。

1. 列出高中生需要理解的概念，先选一个短句作为贯穿例子。
2. 把整体处理流程、注意力机制和一个简单数学例子排成分镜。
3. 让编程助手制作 JavaScript 动画，补上需要的时长、声音和导出要求。
4. 核对权重与概念解释，关闭声音检查图形和字幕能否独立说明。

**值得学习的写法：** 先明确读者能理解到哪一步，再要求整体思路和关键细节都讲清。
