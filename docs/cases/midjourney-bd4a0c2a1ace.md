## 怎么做

以下步骤与练习由本站整理，供学习时参考；作者原文保留在下方。

1. 先分别标记两个实体身影与各自倒影，再用全文生成侧面超远景。
2. 检查人物衣服与形体相同，站位相向且间隔明显大于人物。
3. 让顶灯、建筑和地面反射沿中轴协调，不加第三个实体人物。
4. 检查两个人不被误画成四个实体、反射贴合站位、长距离空间可见、左右建筑对称。

**值得学习的写法：** 先分清实体与倒影，再让建筑、灯与站位共同形成对称。
