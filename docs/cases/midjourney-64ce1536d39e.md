# 侧脸风中的微弱梦境颜料

<CaseTags :item="item" />

九十度侧脸被微弱的薰衣草、玫瑰和蜜金色颜料触碰，发梢化作小光点，下唇边留有单片花瓣碎片。

## 怎么做

以下步骤与练习由本站整理，供学习时参考；作者原文保留在下方。

1. 先固定九十度侧脸和近景，保证鼻尖、嘴唇及下巴形成侧面轮廓。
2. 加入极淡的水彩般梦境颜料，保持皮肤可见；只让发梢出现小光点，别把整头头发变成发光物。
3. 安排左侧冷薰衣草色、右侧暖金色，并在下唇边放一小片花瓣；表情表现被梦境轻触的感觉。
4. 检查视角是否仍为正侧面，颜料是否微弱而非浓重面绘，花瓣是否只有一个局部碎片，冷暖光是否分处两侧。
