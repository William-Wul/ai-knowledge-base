## 怎么做

1. 把15秒分成几个视觉段落，先确定每段的主要变化。
2. 让编程助手用代码合成音乐，并列出节拍与转场时间表。
3. 先导出3秒检查声音，再完整导出并核对每次转场的节拍位置。

**值得学习的写法：** 声音的来源与同步规则一起写清，比只说“加上音乐”更具体。
