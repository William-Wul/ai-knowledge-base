## 怎么做

以下步骤与练习由本站整理，供学习时参考；作者原文保留在下方。

1. 先描述穹顶、顶部圆孔与中央地面三处位置，再按全文生成高位超远景。
2. 把一个小人放在光束落点，保持人物与建筑同时位于中轴。
3. 用薄雾和尘粒显示金色光柱，周围空间仍沉入灰暗，不新增灯具。
4. 检查人物只有一个、光束来自顶孔且垂直、建筑左右对称；人物不能大到失去巨型空间感。

**值得学习的写法：** 同一中轴串起天窗、光柱和人物，尺度由建筑与小人直接比较。
