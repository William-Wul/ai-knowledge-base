## 开始前准备

准备支持参考图的生图工具和视频工具，以及自己的角色或产品素材。这个案例先用分镜图安排镜头，再把分镜用于视频制作。

参考工具：Seedance 2.0、Veo、Kling。

## 怎么做

1. 先阅读分镜要求，替换角色或产品，保留镜头顺序和各段时长。
2. 将分镜图提示词交给生图工具，检查各格的主体、动作、文字与前后关系。
3. 将确认后的分镜图交给视频工具；原文含视频指令时使用对应段落，否则按分镜逐段说明动作与运镜。
4. 检查镜头衔接、人物和产品的一致性，再按顺序拼接片段。

**值得学习的写法：** 先用分镜图把动作和镜头安排清楚，再制作视频；分镜图指令与视频动作指令分别使用。
