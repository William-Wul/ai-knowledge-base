# 花园礼服从裙摆褪成白色睡衣

## 怎么做

以下步骤与练习由本站整理，供学习时参考；作者原文保留在下方。

1. 先安排中央有色花园与周围纯白边缘，颜色从外向内淡去，保留中心鲜艳区。
2. 把礼服花瓣、雪纺或光感面料留在较上部，下方开始显露朴素白棉睡衣，写清从裙摆向上的过渡。
3. 让人物伸手触碰白边，指尖半透明，白色涟漪出现在接触处；目光直视镜头，表达留恋，不必添加对白字幕。
4. 检查褪色方向是否外向内、下向上，睡衣是否与礼服属于同一件过渡衣服，指尖与白边是否接触，是否误加文字或完整第二人物。

**值得学习的写法：** 渐变变化需要指定起点和方向；否则模型容易只给背景加雾，漏掉服装本身的变化。
