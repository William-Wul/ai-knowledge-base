## 开始前准备

准备自己的照片。可替换照片、纸张底色和可选短标题；固定3:4、上下各50%、每张照片独立成图，下半插画约占该半幅10–20%、最多4色。

参考工具：GPT Image 2.5。

## 怎么做

以下步骤与练习由本站整理，供学习时参考；作者原文保留在下方。

1. 先选一张主体清楚的照片，圈出姿势和两个关键物件，再提交完整提示词。
2. 先核对上半幅人物与原照片；需要扩图时只延展周围背景。
3. 下半幅保留同一姿态和物件，用少量平涂色块缩小居中，不强行加字。
4. 检查上下是否等高、下半插画占比与四色情况；人物不能换脸，多张照片不能被拼成一张。

**值得学习的写法：** 原文把照片忠实度与插画简化程度分别限定，同时规定分区和插画占比。
