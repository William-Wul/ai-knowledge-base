# 下方火光照亮的老人侧向凝视

<CaseTags :item="item" />

老人左手护住火把根部，火光从下方刻画皱纹，眼窝隐在阴影中，目光看向画外而不是火焰。

适合练习非常规下方光源与手、火、视线三者的位置关系。

## 开始前准备

可替换：皱纹程度、背景暗度；固定：老人左手拢火根、光由下方来、眼窝全暗、目光朝画外前方，琥珀和黑色为主。是作者艺术人像设定，不是经验证的民族纪实照片。

## 怎么做

以下步骤与练习由本站整理，供学习时参考；作者原文保留在下方。

1. 先安排老人、火把与左手，说明手拢在火焰基部周围，不把手画在火焰中。
2. 让下方橙色火光向上刻画皱纹，眼窝保持完整阴影，不额外加明亮正面补光。
3. 把目光方向设为画外前方，保留手指粗糙感及指甲松脂痕迹，用琥珀与黑色统一画面。
4. 检查是否左手护火根，眼窝是否暗，视线是否没有看火，火光是否由下向上，是否误加第二光源照亮全脸。

**值得学习的写法：** 光源、眼神和手势可以各自有方向；先明确三者，再检查是否被模型合并成常见的看火姿态。
