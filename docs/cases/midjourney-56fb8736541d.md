## 怎么做

以下步骤与练习由本站整理，供学习时参考；作者原文保留在下方。

1. 用白、灰、黑三种主要色建立空旷冰原，天空与雪地尽量接近，避免出现额外深色建筑。
2. 在中心加入高耸镜面黑碑，保持平滑无缝、没有符号或机械结构，基部被积雪包围。
3. 放一个很小的人物作为尺度参照，使用极远景和对称感，让黑碑远大于人物。
4. 检查黑碑是否为主要深色块，表面有无接缝或文字，基部是否没入雪中，人物是否足够小且未增加成队伍。

**值得学习的写法：** 绝对尺寸难从生成图确认，但主体与人物的相对大小和表面规则可以直接检查。
