## 怎么做

1. 先明确横版四个区域：左大头特写，右全身正面、标准侧面、背面，不把三视图画成三个不同人物。
2. 写清圆脸、棕色大眼和蓬松黑短发，保留柔和半写实3D人偶质感。
3. 按同一套清单安排熊徽章马甲、浅蓝衬衫、藏青领带、蓝灰短裤、熊图案袜子、魔术贴鞋和小书包。
4. 检查是否齐全四个视图，侧面是否真侧视，服装与鞋袜颜色是否跨视图一致，书包在正侧背面是否有合理遮挡，背景是否纯白干净。

**值得学习的写法：** 角色设定图首先是连续性练习：每个视图的发型、衣服和配件要能对应，而不是只追求一张精致肖像。
