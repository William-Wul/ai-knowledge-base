# 立体人像与平面色块的混合插画

<CaseTags :item="item" />

把自然可辨的人体和面部塑造成柔和立体体积，再用平面色块、热带配色和流动丝带形成混合插画。

适合练习在同一主体上结合两种画法，而不是把3D人物贴在无关装饰背景上。

## 怎么做

以下步骤与练习由本站整理，供学习时参考；作者原文保留在下方。

1. 先填写三个变量：人物主体、流动装饰的种类、色彩方案；一次只换一项便于判断变化原因。
2. 保留自然五官和人体结构，用柔和明暗表现面部体积，再在局部加入有控制的平面色块与几何轮廓。
3. 让液体丝带、颜料飞溅或有机形状与人物衔接，区分光滑发丝、服装几何块和半透明边缘，背景保持简洁暖色。
4. 检查人物是否仍可辨认，是否同时有立体体积和平面色块，流动元素是否与人物相连，装饰是否遮住主要五官。

**值得学习的写法：** 混合画法要指定两种画法各自负责什么：体积塑造人物，平面色块组织视觉，而不是只堆风格名称。
