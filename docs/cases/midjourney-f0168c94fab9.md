# 红色有机平原上的悬崖眺望者

2. 把地面写成缓慢隆起的有机纹理，明确不是石头、不是水，不用白浪或水面反射代替。
3. 保持暗红与绯红的低饱和配色，使天空和地面难以分辨边界；沿用原参数前另核对工具支持。
4. 检查只有一个主体人物，人物与平原尺度悬殊，地面没有海浪和水线，红色天空与地面未被清晰蓝色地平线分开。
