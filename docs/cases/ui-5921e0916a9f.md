## 开始前准备

## 怎么做

以下步骤与练习由本站整理，供学习时参考；作者原文保留在下方。

1. 选定界面状态与音乐，先画出按节拍排列的状态表。
2. 让编程助手把尺寸、圆角、颜色与光标操作连接在同一条时间线上。
3. 先每拍抽一帧，检查文字替换有没有重叠、滑块是否跟随拖拽。
4. 检查首尾的光标位置和速度一致，再导出循环视频。

**值得学习的写法：** 让形状与光标动作相互对应，状态变化才有因果关系。
