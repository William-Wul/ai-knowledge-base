# 头盔玻璃里的黑洞倒影

<CaseTags :item="item" />

宇航员头盔极近景中，弯曲玻璃映出黑洞与发光吸积盘，脸只有一只眼睛亮起，形成冷蓝与铜琥珀的强烈对照。

适合练习透明面罩同时保留反射景象、眼睛和细小划痕。

## 怎么做

以下步骤与练习由本站整理，供学习时参考；作者原文保留在下方。

1. 先将头盔面罩放满近景，明确黑洞和明亮吸积盘是玻璃反射，避免直接画在人物脸上。
2. 安排半脸阴影和一只亮眼，保留汗珠、皮肤纹理及敬畏与恐惧的表情。
3. 用冷蓝面部环境色与铜琥珀反射区区分层次，并加入少量玻璃划痕，不用柔化滤镜消除细节。
4. 检查倒影是否随玻璃曲面弯曲，眼睛是否仍可见且只亮一只，划痕是否在面罩而非皮肤，黑洞倒影没有盖满全部五官。

**值得学习的写法：** 透明物体可以同时有前表面划痕、反射和后方人物，逐层描述能减少模型把它们混成一张脸的概率。
