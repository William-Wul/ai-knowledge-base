# 湖岸旅人与水中的同一倒影

## 开始前准备

可替换：远岸人物间距、丝巾曲线；固定：近岸旅人平躺、平行水边且离水约一臂，倒影来自同一人，湖水映蓝天雪山，午后暖侧光。民族身份与场景是艺术设定，不代表真实纪实记录。

## 怎么做

以下步骤与练习由本站整理，供学习时参考；作者原文保留在下方。

1. 先画近岸平躺人物与水平水线，保持身体贴地、与岸平行，而不是站立或趴进湖中。
2. 让镜面水中的倒影与岸上人物位置、姿态相对应，明确是反射而非水里另有一个人。
3. 加入半浸白丝巾、远岸一列旅人及蓝天雪山倒影；用暖砾石侧光对比深蓝湖水。
4. 检查近岸主体只有一人，倒影的朝向和身体姿态是否对应，人物与水线是否平行，丝巾是否在水面，远岸人物是否没有挤到前景。

**值得学习的写法：** 画面中的“两个人影”可能是一个人及其反射，先说明物理关系再数画面形状。
