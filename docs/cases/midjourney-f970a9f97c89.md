## 怎么做

以下步骤与练习由本站整理，供学习时参考；作者原文保留在下方。

1. 先指定8人作为8–10范围内的一次尝试，用全文请求围圈中景。
2. 检查黑裙、红黄刺绣、银冠链条与火把在各人身上是否协调。
3. 让裙摆外展和暖金光围成圈，观众只在边缘出现，避免主舞者排成直线。
4. 数清主圈人数，检查火把和手没有粘连、银冠未变成头发、中央留出围圈空间。

**值得学习的写法：** 用数量范围和重复服饰，让群像构图有可数、可比较的元素。
