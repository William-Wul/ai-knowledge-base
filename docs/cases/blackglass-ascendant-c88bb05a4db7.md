## 开始前准备

先准备文字对话工具，将下方模板连同自己的主题或参考图交给它，得到生图提示词；再把提示词交给图片生成工具。

参考工具：Nano Banana Pro。

## 怎么做

1. 阅读模板，确定主体、材质和光线要求。
2. 将模板与自己的主题交给文字对话工具，让它整理成生图提示词。
3. 把整理后的提示词与参考图交给图片生成工具，先生成一张。
4. 检查主体轮廓与暗部细节，针对问题调整光线或材质描述。

**值得学习的写法：** 把主体、画面布局、风格与限制分开描述，比只写一个风格名称更容易说明目标。
