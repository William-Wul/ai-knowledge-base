## 开始前准备

准备产品名称、3至5个真实界面片段、10至20条自有竖版视频和约120 BPM的音乐。原文用10个小节、每小节2秒安排结构；需要核对实际歌曲节拍，不能只按文本机械拼接。

参考工具：Claude Opus 5.5。

## 怎么做

以下步骤与练习由本站整理，供学习时参考；作者原文保留在下方。

1. 提交产品、真实界面、强调色、视频与音乐，先核对宣传事实。
2. 按作者结构给出踩节拍的分镜，标出真实素材与界面动画的交接。
3. 让编程助手将片段抽帧与动画结合，先检查20帧以上的关键位置。
4. 核对文字可读、素材来源、音效音量和镜头节奏后导出。

**值得学习的写法：** 画面里的素材与结果必须真实，每个镜头只传达一个信息。
