## 怎么做

以下步骤与练习由本站整理，供学习时参考；作者原文保留在下方。

1. 先安排中央旅人和垂直树列，形成可看入深处的森林走廊，森林大面积保持钢蓝暗部。
2. 分别把生日、战场和方程式片段放在树干周围，说明它们从树皮向空中投影，不是树上挂实体显示器。
3. 用琥珀记忆光照亮人物半脸，地面反射呼应投影，避免各片段都占满主体。
4. 检查投影是否来自树干，三个记忆题材是否可分辨，旅人是否仍居中且半脸受光，地面反射是否对应附近光源。

**值得学习的写法：** 多故事片段可以靠共同的光源和投影机制统一；次要画面太大就会把森林主体挤掉。
