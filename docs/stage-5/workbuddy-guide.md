## 一、先搞懂它是什么

WorkBuddy 是腾讯云 CodeBuddy 团队出的一个 **AI 桌面助手**——它是一个装在电脑上的软件，你用大白话交代一件事，它自己拆步骤、读文件、调工具、把活干完，最后把成品交给你。

它和你平时用的 AI 聊天工具（豆包、DeepSeek 网页版、ChatGPT 这些）的区别，一句话就能讲清：

这种"接到任务后自己规划步骤、自己调用工具、自己检查结果，一路干到任务完成"的 AI，就是大家常说的 **Agent（智能体）**。

## 二、几个名词先说清

后文会反复出现几个词，先用大白话解释一遍，零基础的朋友也能跟下去：

- **积分（Credits）**：WorkBuddy 的"额度单位"。你每让它干一次活，就消耗一点积分——简单任务（写封邮件）耗得少，复杂任务（生成一份带图表的报告）耗得多。免费版每月送一些，用完了可以升级付费版。
- **工作空间**：可以理解成"项目文件夹"。你给一个任务指定工作空间后，它读文件、存成果都在这个文件夹里，不同项目互不干扰。
- **技能（Skills）**：给 AI 加装的"能力包"。比如装一个 PPT 技能，它做出来的 PPT 就明显更专业——因为技能里封装了这个领域的成熟做法。
- **连接器**：把 WorkBuddy 和你在用的外部服务接起来的"插头"，比如接上 QQ 邮箱后它就能替你收发邮件。技术圈管这个机制叫 MCP，在 WorkBuddy 里你只要记住"连接器 = 插头"就够了。
- **专家**：预先封装好的"垂直领域 AI 角色"，比如财务专家、法律专家。召唤一个专家，相当于换了个带专业背景的人来接你的活。

## 三、下载安装

WorkBuddy 的官网：

```
https://workbuddy.cn
```

（这个地址会带你到腾讯 CodeBuddy 官网的 WorkBuddy 页面，看到 `codebuddy.cn/work` 开头的网址不用慌，是同一个官网。）

打开后点"下载"，**Mac 和 Windows 都支持**，选你电脑对应的系统：

![WorkBuddy 官方下载页：Mac 分 Apple 芯片和 Intel 芯片两个版本，Windows 一个版本通用](/images/stage-5/wb-download.png)

*下载页示意：Mac 用户注意分"Apple 芯片"和"Intel 芯片"两个版本，Windows 用户直接下 x64 版*

> 💡 **Mac 用户怎么知道自己是哪种芯片？** 点屏幕左上角苹果标志 →「关于本机」，写着 "Apple M…"（M1/M2/M3 等）就选 Apple 芯片，写着 "Intel" 就选 Intel。2020 年底以后买的 Mac 基本都是 Apple 芯片。

**配置要求很低**：Windows 10/11 或 macOS 12 以上，4GB 内存就能跑——因为 AI 计算在云端完成，你的电脑只负责界面和文件读写，不需要好显卡。

下载安装：

- **Mac 用户**：双击下载的 .dmg 文件，把 WorkBuddy 图标拖进"应用程序"文件夹就装好了。
- **Windows 用户**：双击 .exe 安装包，一路"下一步"，看到下面这个界面就是装好了：

![Windows 安装完成界面，勾选"运行 WorkBuddy"后点完成](/images/stage-5/wb-install-windows.png)

*Windows 安装向导走完的样子：勾上"运行 WorkBuddy"，点"完成"直接打开*

> ⚠️ **Mac 第一次打开提示"无法验证开发者"？** 去"系统设置 → 隐私与安全性"，往下拉找到关于 WorkBuddy 的提示，点"仍要打开"即可。这是 macOS 对所有非 App Store 软件的统一安全机制，不是软件有问题。

## 五、认识界面

登录后是主界面。看着东西多，其实理解三层就够了：**中间选场景，下面写任务，输入框周围是几个开关**。

![WorkBuddy 主界面：顶部是三个场景模式，中间是快捷模板，底部是输入框和各种开关](/images/stage-5/wb-ui-main.png)

*主界面：上方"代码开发 / 日常办公 / 设计创意"三个场景模式，中间一排是该场景下的任务模板，最下面是输入框*

### 5.1 三个场景模式

界面正中有三个按钮——**代码开发、日常办公、设计创意**。它们相当于"频道"，切换后下面的任务模板会跟着变：

- **日常办公**：文档处理、数据分析及可视化、深度研究、幻灯片、邮件……大多数人用得最多的就是这个
- **代码开发**：网站开发、Agent 应用开发等，第十二章会演示
- **设计创意**：网站设计、PPT 设计、品牌设计、交互原型等

模板点进去是写好的提示词框架，把里面的内容换成你的实际需求就能发——不会写提示词的新手可以直接"填空"。

*Plan 模式的体验：它把不确定的细节做成选择题问你，确认完才动手——这就是"先商量、再干活"*

### 5.3 选模型

工作模式旁边是**模型选择**。模型就是 AI 的"大脑"，WorkBuddy 内置的都是国产大模型——腾讯混元、DeepSeek、GLM、Kimi、MiniMax 都有，右侧的数字是各模型的积分消耗倍率：

![模型选择菜单：内置混元、GLM、Kimi、DeepSeek、MiniMax 等国产模型，标注了积分倍率](/images/stage-5/wb-model-picker.png)

*模型菜单：不同模型积分倍率不同。不想纠结就选 Auto（让它自动挑），想自己定就看下面的建议*

不知道选哪个？给一个省心的方案：

- **就要一个最通用的**：选 **DeepSeek V4 Pro**——综合能力强、积分倍率不高，对绝大多数人是"水桶型"选择
- **写中文文案多**：混元对中文场景优化好
- **读长文档、写长文**：Kimi 擅长长文本
- **想省积分**：MiniMax 或带 Flash / Turbo 字样的轻量版

> 💡 进阶用户如果有自己的模型 API Key（就是调用模型服务的"钥匙串"），在设置 → 模型里点"添加模型"，凡是兼容 OpenAI 协议的服务都能接进来。新手跳过这段，用内置的就好。

### 5.4 权限和工作空间

输入框右边还有一个**权限**开关，两档：

- **默认权限**：遇到删文件、发邮件这类高风险操作，先停下来问你——**新手用这档**
- **完全访问**：全程不打扰，一口气干到底——等你用熟了、对它有信心了再开

输入框下面的**选择工作空间**，就是给任务指定"项目文件夹"。你可以新建一个空间，也可以打开电脑上已有的文件夹让它直接处理里面的文件。一开始没选也没关系，任务跑完后可以再保存进空间。

> 💡 **前期把分类做好**：不同的事用不同的工作空间（比如"周报"一个、"项目A"一个），别什么都堆在一起。任务多了之后，找东西的痛苦程度天差地别。任务列表里还可以给任务重命名、归档，都是为了同一个目的：**让三个月后的你还找得到今天的活。**

## 六、调好关键设置

点左下角头像 → 设置。有几个开关强烈建议跟着调，一次调好长期受益：

![系统设置页面：技能自动更新和锁屏远程两个开关](/images/stage-5/wb-settings.png)

*系统设置里重点开两个：①技能自动更新 ②锁屏远程*

1. **技能自动更新**（系统设置）：你装的技能有新版本会自动升级，不用手动维护
2. **锁屏远程**（系统设置）：开启后电脑锁屏也不休眠——后面第十一章讲的"手机远程指挥电脑"，靠的就是电脑保持在线，这个开关是前提
3. **系统授权**（系统授权页）：按提示把文件访问等权限授了，它才能替你操作文件
4. **对话记忆**（记忆页）：开启后它会从对话里提取你的习惯偏好记下来，越用越懂你；之前用过别的 Agent 的话，还能把那边的记忆导过来
5. **自定义指令**（个性化页）：给它立的"长期规矩"，写一次，以后每次干活都自动遵守

> 💡 **自定义指令写什么？** 这相当于 Claude Code 的 CLAUDE.md / Codex 的 AGENTS.md——我们在那两篇教程里推荐过的"卡帕西四条"，这里照样适用，直接抄进去：①**先想再做**（动手前先说清你的理解，不确定就问我）；②**简单优先**（只做我要求的事，别自作主张加戏）；③**外科式修改**（只动该动的，别顺手大改其他东西）；④**目标驱动**（把任务变成可检验的结果，做完自己核对）。

## 七、跑通第一个任务

光看不练没感觉。这一章我们完整跑一个最典型的办公任务：**让它基于一份数据文件，生成一份周会汇报。**（你手头没有现成数据的话，换成"把我桌面的文件按类型分类整理"也一样，节奏是相同的。）

**第一步：切到"日常办公"模式**，点"选择工作空间"，选中存放数据文件的文件夹（或者直接点输入框右边的 ➕ 上传文件）。

**第二步：用大白话说需求**，比如：

```
帮我基于上周的销售数据，生成一份报告，在周会中进行汇报
```

**第三步：点一下"优化提示词"**。输入框右下有个魔法棒一样的小按钮，点它，AI 会把你这句大白话扩写成一份结构化的需求清单，你过目确认：

![优化提示词后的效果：一句"帮我生成周会报告"被扩写成包含数据指标、表现分析、报告格式的完整需求清单](/images/stage-5/wb-prompt-optimized.png)

*一句大白话被扩写成了结构化需求：要分析哪些指标、报告什么格式、做哪些图表都列清楚了。这一步对出活质量帮助很大，建议养成习惯*

**第四步：发送，看它干活。** 界面上会出现一个**任务清单（Todo）**，它正在做哪步、接下来做什么，一目了然：

![任务执行中的 Todo 清单：读取数据、计算指标、分析、生成图表、输出 Word 文档，逐项打勾](/images/stage-5/wb-task-todo.png)

*执行过程全透明：它把任务拆成五步，做完一步勾一步——这就是 Agent 和普通聊天 AI 的本质区别*

**第五步：验收成果。** 跑完后右侧边栏能直接预览产出的文件，也可以点"打开文件夹"看原文件：

![生成的周报：带柱状图、排行榜和分析结论的正式报告文档](/images/stage-5/wb-report-result.png)

*它交出来的不是一段聊天回复，而是一份带图表、带结论、排好版的 Word 报告——这就是"交付成品"的意思*

到这里你已经体验完整个节奏了：**说需求 → （优化提示词）→ 看它分步执行 → 验收文件。** 文档、表格、PPT、数据分析，全是这个节奏的变体。

> 💡 **不满意？接着说就行。** "把图表换成饼图""结论部分再精简一半""生成一版 PPT 摘要"——它会在原有基础上继续改，不用从头来。

## 十四、安全注意事项

Agent 能动你的真实文件、发真实的邮件，能力越大，越要懂边界。三条原则：

1. **最小授权**：只给它需要的文件夹权限（桌面、文档、下载够用了），财务、人事这类敏感文件夹别一股脑全开，用到再单独授权
2. **高风险操作留确认**：新手阶段权限选"默认权限"，删文件、发邮件前它会先问你——这一道确认，挡住的是"它理解错了你的意思"的情况
3. **第三方技能先审后装**：来路不明的技能不装；装之前看介绍、看评价

> 💡 数据安全方面：WorkBuddy 是腾讯官方产品，传输加密，文件处理在你本地完成。但任何工具都一样——**真正敏感的东西（密码本、机密合同），从一开始就别放进它的授权范围**，这是比信任任何厂商都可靠的做法。

## 十五、常见问题

**Q1：WorkBuddy 是免费的吗？**

有免费的个人体验版，每月送一些积分，轻度使用够了。重度用户可以上 58 元/月的专业版。新用户注册和日常签到都有积分赠送，具体政策以页面显示为准。

**Q2：我完全不懂技术，能用吗？**

能，而且它可能是这一类工具里对小白最友好的：图形界面、微信登录、模板填空、专家市场——全程不需要碰命令行。这篇教程里所有操作都是点按钮完成的。

**Q3：它和 Claude Code、Codex 怎么选？**

不冲突。能用上 Claude Code / Codex 的，开发类任务优先用它们（模型更强）；日常办公自动化、以及"国内开箱即用"这个需求，WorkBuddy 是目前体验最顺的答案之一。很多人是组合着用的。

**Q4：手机远程控制，电脑关机了还能用吗？**

"连接电脑"模式不行——它操控的就是你那台电脑，电脑得开着（锁屏没关系，记得开"锁屏远程"）。但"云端工作"模式可以，任务跑在云端，不依赖你的电脑。

**Q5：它能处理哪些文件？**

Word、Excel、PPT、PDF、图片、纯文本这些主流办公格式都支持，能读、能改、能合并转换、能提取信息。

**Q6：积分用得太快怎么办？**

三个省积分的习惯：①指令一次说清楚（四要素公式），减少来回返工；②简单任务用轻量模型（带 Flash / Turbo 字样的）；③别用专家团干简单活。另外每日签到能领免费积分。

## 十六、下一步去哪

跑通第一个任务只是开始。接下来值得做的三件事：

- **把你工作里最烦的一件重复事自动化**：用第十章的方法设一个定时任务，真正体会"它在替我打工"的感觉
- **把常用流程封装成技能或专家**：反复要做的事，封装一次，以后一句话调用
- **学有余力，补上开发这条线**：办公自动化用顺之后，可以把 Claude Code、Codex 这类开发向的 Agent 也装上摸一遍——几类工具都用过，你对"Agent 能干什么"就有完整的体感了
