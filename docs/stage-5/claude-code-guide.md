# Claude Code 从零开始：保姆级完整教程

> 不翻墙也能用 · Mac + Windows 双线 · 接国产模型全流程 · 从第一行命令到真正干活

---

这是一篇很长的教程。

但你不需要一口气读完——翻到你需要的那一节，跟着做，就行。

**读完这篇，你能做到五件事：**

1. 在自己的电脑上装好 Claude Code（Mac 或 Windows，有没有翻墙都行）
2. 给它接上一个真正好用的大模型（官方 Claude 或国产模型）
3. 跑通第一个任务，亲眼看它干活
4. 知道怎么好好跟它说话，不走弯路
5. 遇到问题知道怎么急救

---

## 一、先搞懂它是什么

很多人装了 Claude Code，用着用着就用废了。原因几乎都一样：**以为它是一个更聪明的 ChatGPT。**

它不是。

Claude Code（以下简称 CC）的工作方式跟你熟悉的 AI 聊天完全不同。

普通 AI 对话：你问一句，它答一句。每一轮都是独立的。

CC 的工作方式：你交代一件事，它自己规划步骤、自己调工具、自己看结果、自己再决定下一步——反复循环，直到任务完成或卡住为止。这个过程叫 **Agent Loop（循环执行）**。

![](/images/stage-5/cc-llm-loop-diagram.png)

*CC 的工作流：你说"帮我整理文件夹"，它自己决定先读文件、再归类、再创建文件夹……一步步做完，而不是等你每步都下指令*

一句话总结：**CC 是一个能直接上手帮你把事情做完的 AI**——不是再来一个聊天框。

这是它跟 ChatGPT、DeepSeek 网页版最大的区别：那些是"陪你聊"，CC 是"替你做"。

---

## 二、两个名词先说一下

为了让真正零基础的朋友也能跟下去，先把后文要反复出现的两个词解释清楚。

**终端 / 命令行**：黑乎乎、只能打字、没有按钮和图标的窗口。Mac 上叫"终端"，Windows 上叫"PowerShell"或者"终端"。我们整篇教程会多次让你打开它、粘贴一行命令、按回车——别怕，跟着做就行。

**命令**：你在终端里敲的那一行英文字符。比如 `claude --version` 就是一条命令，它的意思是"问 Claude Code 自己的版本号"。命令必须**完整复制**，不能少字符、不能多空格。

> 💡 **小白须知**：本文里所有出现在灰色代码块里的内容，都是要你完整复制粘贴到终端的命令。复制时点代码块右上角的"复制"按钮最稳妥，不要手敲（容易打错）。

## 三、在开始之前：选你的路线

CC 本质上是一个 **Agent 框架**，它本身不绑定任何特定的大模型。

你可以给它接官方的 Claude 模型（需要翻墙 + 海外账号 + 付费），也可以接国内的大模型（GLM、DeepSeek、Kimi 等），完全不需要翻墙。

在装 CC 之前，先想清楚你打算接哪个模型：

| 你的情况 | 推荐路线 | 关于费用 |
|---|---|---|
| 没翻墙 / 翻了但没有 Claude 账号（**绝大多数人**） | **路线 A：CC Switch 接国产模型**（DeepSeek / GLM / Kimi 等） | 都是按用量付费，**建议先从 DeepSeek 试**（国内最便宜、编程能力强），充 10 块钱能跑很久；用熟了再按口味换 GLM / Kimi |
| 有翻墙 + 有 Claude Pro/Max 订阅 | 路线 B：官方原生 `/login` 登录 | Claude Pro 约 ¥150/月、Max 约 ¥700/月起，模型能力最强（2026 年 6 月起官方最强模型是 Fable 5，比 Opus 系列还高一级；Max 套餐内含一定额度，Pro 需额外用量点数） |

> ⚠️ **选路线 B 之前，先知道"封号潮"这件事。** 从 2025 年下半年起，Anthropic 就在大规模封禁账号——官方数据是半年封了约 145 万个，申诉成功率只有 3.3%；2026 年风控更是覆盖注册、订阅、使用的全程。对国内用户来说，高危动作是这几个：**虚拟信用卡付费、多人拼车共用一个号、来路不明的代充、IP 频繁切换**。要走官方路线，记住三条：账号注册在自己名下、支付方式和登录环境尽量干净固定、别碰拼车。想省心就老实走路线 A，国产模型现在很能打，而且不存在封号这回事。封号潮的来龙去脉，站内[《GPT-6 Astra 发布：Claude 封号潮后的白月光》](/frontier/gpt6-astra-after-claude-ban-wave)讲得比较全。

> 💡 **小白常见误区**：国产模型不是"完全免费"。虽然有些（比如 GLM）注册送一点免费额度，但真正用起来需要按 Token 计费。**好处是国内便宜、不用翻墙**；代价是跟 Claude 官方最强模型仍有差距，但 2026 年下半年这个差距已经明显缩小——DeepSeek V4 Pro、GLM-5.3、Kimi K3 这一档在编程任务上相当能打，Kimi K3 还在编程盲测榜上排到过第一。建议都试一试，找到自己满意的。

不管你选哪条路，**CC 的安装步骤是一样的**——只是安装命令分"没翻墙的国内路线"和"有翻墙的官方路线"两种。下面我们**先讲不需要翻墙的**，再讲翻墙的。

## 四、第一步：装 Claude Code

下面我们**先讲不需要翻墙的两条路**（Mac/Windows 都覆盖），再讲翻墙的两条路。挑你的情况看就行。

---

### 4.1 Mac · 没有翻墙（推荐绝大多数 Mac 用户）

没有翻墙不要紧，我们用 **Homebrew** 来装——Homebrew 是 Mac 上最流行的"软件管理工具"，可以理解为"Mac 的命令行版应用商店"。装好它之后，所有软件一行命令就能装。

> ⚠️ **关于网络**：Homebrew 本身不需要翻墙，但它的安装脚本是从 `raw.githubusercontent.com` 下载的，**这个域名在国内有时候会抽风**（一会儿通一会儿不通）。如果下面这步卡住或报错，先换个网络（手机热点、办公室 Wi-Fi、家里 Wi-Fi 多试几个），或者搜"Homebrew 国内镜像安装"用清华/中科大镜像。

**第一步：打开终端**

按一下 `Command + 空格` 调出 Spotlight 搜索，输入"终端"两个字，第一个匹配就是，按回车打开。

**第二步：装 Homebrew**

把下面这行命令完整复制（很长但是一整行，别拆开），粘贴进终端，按回车：

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

按下回车后，它会先问你电脑的开机密码（输入的时候屏幕不会显示你输的字符，这是正常的安全设计，不要慌，输完按回车），然后列出要安装到哪些目录，最后让你按一下回车确认开始：

![](/images/stage-5/cc-mac-brew-confirm.webp)

*依次会经过：(1) Password: 输入你的开机密码，(2) 列出要安装的目录，(3) "Press RETURN/ENTER to continue"，按一下回车继续*

接下来 Homebrew 会自动下载、安装，**整个过程大概 3–10 分钟**（取决于你的网速）。期间不要关窗口。

**第三步：配置 Homebrew 的路径**

装完之后，屏幕上会出现 "Installation successful!"，然后还有一段叫 "Next steps" 的内容，里面**有三行命令**：

![](/images/stage-5/cc-mac-brew-path-nextsteps.webp)

*红框里那三行命令，是要把 Homebrew 加进系统路径——这步不做的话，后面输入 `brew` 命令会找不到*

这三行命令**每个人的电脑显示的内容会略有不同**（里面有你的用户名）。**最稳的办法是从你自己屏幕上复制**。

如果你的 Mac 是 Apple Silicon（M1/M2/M3/M4 系列，2020 年之后买的基本都是），下面这版可以**通用直接复制**：

```bash
echo >> ~/.zprofile
echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile
eval "$(/opt/homebrew/bin/brew shellenv)"
```

粘贴到终端，按回车执行。执行完提示符回到正常状态就说明配置好了。

**第四步：用 Homebrew 装 Claude Code**

继续在终端粘贴：

```bash
brew install --cask claude-code
```

安装可能需要几分钟，等到屏幕出现 "successfully installed" 就完成了。

最后输入下面这条命令验证：

```bash
claude --version
```

看到版本号（比如 `2.1.110 (Claude Code)`）就大功告成。

### 4.2 Windows · 没有翻墙（推荐绝大多数 Windows 用户）

Windows 有自己的官方软件管理工具叫 **winget**（类似 Mac 的 Homebrew），直接用它来装，**完全不需要翻墙**。

**第一步：打开终端**

在 Windows 任务栏的搜索框里输入"终端"，找到结果里的"终端"应用，点击打开（不要选"命令提示符"，要选"终端"或"Windows PowerShell"）：

![](/images/stage-5/cc-win-search-terminal.webp)

*在 Windows 搜索栏搜"终端"，点最佳匹配里的那个紫色图标应用*

**第二步：用 winget 装 CC**

在打开的 PowerShell 窗口里粘贴下面这条命令，按回车：

```powershell
winget install Anthropic.ClaudeCode
```

![](/images/stage-5/cc-win-winget-install.webp)

*winget 会自动从微软的官方源下载 Claude Code（大约 233MB），下载完自动安装，整个过程几分钟搞定*

**第三步：验证**

安装完成后，在同一个 PowerShell 窗口里直接输入：

```
claude
```

按回车，看到橙色小机器人的欢迎界面就装好了：

![](/images/stage-5/cc-win-cc-welcome.webp)

*看到"Welcome to Claude Code" + 橙色小机器人 + 月亮图案就说明 CC 在你电脑上跑起来了*

### 4.3 Mac · 有翻墙

有翻墙的话可以直接走 Anthropic 官方的一行命令，比 Homebrew 简单。

**第一步：打开终端**——按 `Command + 空格`，输入"终端"，回车打开。

**第二步：粘贴下面这条命令，回车：**

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

稍等十几秒到一分钟，看到如下界面就说明装好了：

![](/images/stage-5/cc-mac-install-success.png)

*装好的样子：绿色的 ✓ + "Claude Code successfully installed!" + 版本号*

**第三步：可能会出现的 PATH 警告（不是每个人都会出现）**

如果你在装好的界面**下方看到一段黄色的 ⚠️ 警告**：

> Native installation exists but `~/.local/bin` is not in your PATH.

这意思是：CC 装好了但系统不知道去哪里找它。解决办法是在终端里粘贴下面这条命令：

```bash
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc && source ~/.zshrc
```

> 💡 如果你装完没看到这条黄色警告（不少 Mac 第一次装就没这个问题），**直接跳过第三步**，进入第四步即可。

**第四步：验证安装**

```bash
claude --version
```

看到版本号就成了。

### 4.4 Windows · 有翻墙

**第一步：打开 PowerShell**（搜索栏搜"终端"，参考上面 4.2 的截图）。

**第二步：粘贴下面这条命令，回车：**

```powershell
irm https://claude.ai/install.ps1 | iex
```

等大约 30 秒到 1 分钟，看到"Claude Code successfully installed!" + 版本号就装好了。

**第三步：验证**

```powershell
claude --version
```

看到版本号说明成功。

## 五、第二步：给 CC 接上"大脑"

CC 装好了，但现在还不能用——它没有大模型，就像你买了一部手机但还没插 SIM 卡。

接下来根据你之前在第三章选的路线操作。**先讲多数人用的路线 A**（CC Switch 接国产模型），再讲路线 B（Claude 官方账号登录）。

---

### 路线 A：用 CC Switch 接国产模型

如果你没有 Claude 官方账号，或者不想/不能翻墙，就用 **CC Switch**。

CC Switch 是一个专门给 CC 用的"模型切换器"，它把所有跟模型相关的繁琐配置封装成了一个图形界面——你只需要点几下、填一个 API Key，它帮你搞定剩下的一切。

---

#### 安装 CC Switch · Mac

Mac 上有两种装法，挑你方便的：

**方法一：用 Homebrew 装（推荐，如果之前走过 Mac 无翻墙路线，已经有 Homebrew）**

在终端里依次运行这两行：

```bash
brew tap farion1231/ccswitch
brew install --cask cc-switch
```

等待安装完成，屏幕上会出现"cc-switch was successfully installed!"：

![](/images/stage-5/cc-mac-ccswitch-install.webp)

*CC Switch 在 Mac 上通过 Homebrew 安装完成，最后一行的"cc-switch was successfully installed!"是成功标志*

**方法二：直接下载 dmg 安装包（适合没装 Homebrew 的人）**

浏览器打开 `https://github.com/farion1231/cc-switch/releases`，找列表里带 `macOS.dmg` 字样的文件下载，双击打开，把 CC Switch 图标拖进 Applications 文件夹就装好了。

装好后，去"启动台 / 应用程序"里找"CC Switch"图标，双击打开它。

---

#### 安装 CC Switch · Windows

Windows 需要去 GitHub 下载安装包。

打开浏览器，访问：`https://github.com/farion1231/cc-switch/releases`

![](/images/stage-5/cc-ccswitch-github-releases.webp)

*CC Switch 的 GitHub 发布页面。在列表里找带 "Windows.msi" 字样的那个文件下载（图中红框标注的）*

> ⚠️ **没有翻墙的朋友**：GitHub 在国内有时候打不开。**请只从上面的官方 releases 页下载，不要去小红书/B 站找"网友打包好"的安装包**——这类工具收到的 API Key 价值很高，已经出现过被改包窃 Key 的事故。
>
> 打不开 GitHub 的话，先换个网络（手机热点、办公室 Wi-Fi 多试几个）；实在不行，可以用 GitHub 的国内访问加速服务（搜"GitHub 国内加速"），或者请有翻墙能力的朋友帮你下完官方包再发给你。

下载完后双击 `.msi` 安装包，按向导一路点 Next 装完：

![](/images/stage-5/cc-ccswitch-win-wizard.webp)

*CC Switch 的 Windows 安装向导，点 Next 一路装完就行*

装好后，开始菜单里能找到 "CC Switch"，点开。

---

#### 在 CC Switch 里配置模型（配好就能用）

第一次打开 CC Switch，你会看到这个主界面：

![](/images/stage-5/cc-ccswitch-main-ui.webp)

*CC Switch 主界面：顶部是 Claude / Codex / Gemini / OpenCode / OpenClaw 等标签，下方是已添加的供应商列表。右上角橙色的 ➕ 号就是"添加新供应商"*

点击右上角橙色 ➕ 号，进入"添加新供应商"界面。

CC Switch 贴心地内置了大量**预设供应商**——你不需要自己去查什么 URL、什么参数，**直接点你想用的那个就行**：

![](/images/stage-5/cc-ccswitch-presets.webp)

*预设供应商列表，包含 Zhipu GLM、DeepSeek、Kimi、MiniMax、DouBaoSeed 等十几个常用国产模型。直接点你要用的那个（这里以 Zhipu GLM 为例）*

**新手推荐先选 "DeepSeek"**——国内最便宜的一档，编程任务能力强，充 10 块钱能跑很多。它家模型分 Flash 和 Pro 两档，新手用便宜的 Flash 档就够。用熟了再按口味试试 GLM、Kimi 等。

点完预设供应商，进入填写表单页面。**对小白来说，整个表单实际只有两个红框里的字段必须自己填**：

![](/images/stage-5/cc-ccswitch-form-clear.webp)

*整个表单里被红框框出的就是关键字段：**最上面那框**是供应商名称（你随便起，比如 "我的GLM"）；**中间那框**是 API Key（粘贴你去官网申请到的密钥）；**下面那框**是请求地址（**选了预设供应商这里会自动填好，直接用就行**；只有"自定义配置"才需要自己填）；**右下角那框**是"+ 添加"按钮（最后保存用）*

**怎么拿 API Key？**

> ⚠️ **新手必看：拿到 Key 不等于能用**
>
> 很多小白拿到一串 API Key，配进 CC Switch 之后却报错"额度不足"或"未开通服务"。原因是：
>
> **国产模型平台普遍是"注册账号 + API Key + 充值/开通套餐"三步缺一不可**。光创建了 Key 但没充值，照样调不通。第一次用，**建议先充 10 块钱试水**，能跑非常多任务；用顺手再加充。

以 DeepSeek 为例（推荐新手首选，国内最便宜）：

1. 浏览器打开 `https://platform.deepseek.com`（国内可直接访问）
2. 注册账号 → 登录
3. **充值**：找"充值"或"余额管理"，最少充 10 块钱（实测能跑很多任务）
4. 找"API Keys"页面 → 点"创建 API Key" → 复制那串字符
5. 粘贴回 CC Switch 的"API Key"输入框

GLM、Kimi、MiniMax 等其他平台流程类似——**核心都是：注册 → 充值/开通 → 创建 Key → 复制粘贴**。

然后往下滚，在"模型映射"部分填好你要用的模型名称：

![](/images/stage-5/cc-ccswitch-models-and-add.webp)

*"模型映射"部分有 5 个字段：主模型 / 推理模型 (Thinking) / Haiku / Sonnet / Opus 默认模型。图里的填法是 `glm-5.1` 和 `glm-5` 混填（截图时的版本，现在 GLM 已更新到 `glm-5.3`）——**对小白来说，5 个字段全部填同一个最新模型名更省事**，效果一样。模型名以你充值时各平台公布的为准，填完点右下角红框的 **"+ 添加"** 按钮保存*

填完点"+ 添加"保存，回到 CC Switch 主界面。**关键的最后一步：把刚加的这个供应商点亮（变成"使用中"）**：

![](/images/stage-5/cc-ccswitch-using.webp)

*配好之后，主界面会出现你刚加的这一行。**鼠标移到那一行，点一下让它显示"✓ 使用中"**（图中那个灰色的"使用中"标记）——这一步不做的话，CC 还是会去找你原来的配置*

到这一步，**关闭 CC Switch 窗口（不用退出后台，留着即可）**，然后去启动 CC，它就会自动用你刚配的供应商了。

> ⚠️ **新手最容易翻车的点**：CC Switch 必须在 CC **没启动**的情况下切换供应商。如果你已经在 CC 里了，先用 `/exit` 退出 CC，回到普通终端，再去 CC Switch 切换。

### 路线 B：用 Claude 官方账号登录（需要翻墙）

如果你有 Claude 的 Pro 或 Max 订阅账号，这是最简单的方式，直接用官方模型，效果最好。

⚠️ **前提**：这条路线**自始至终都需要翻墙**。登录过程中会弹出浏览器去 claude.ai 完成授权，没有翻墙打不开。

> ⚠️ **再提醒一次封号风险**（第三章详述）：2025 下半年以来 Anthropic 封号力度很大，虚拟卡付费、拼车、代充、IP 乱跳都是高危动作。账号要用自己的、环境要稳定；万一被封，官方申诉成功率很低（约 3.3%），所以从一开始就别把重要工作只押在一个账号上。

在终端里输入 `claude` 启动 CC，然后在 CC 的输入框里输入：

```
/login
```

![](/images/stage-5/cc-login-screen.webp)

*输入 /login 后，CC 让你选登录方式：1. Claude 订阅账号 / 2. API 按量计费 / 3. 第三方平台*

用 ↑↓ 方向键移到第一项 "Claude account with subscription"，按回车选中。它会自动弹出浏览器让你用 Claude 账号登录，登录完浏览器会显示"登录成功，可以关掉此页"，回到终端 CC 就配好了。

## 六、第三步：选你的"工位"——直接用终端，还是搭 IDE

CC 装好之后，有两种用法。**新手选一种就行**：

### 路线 ① 直接用系统终端（最简单，0 额外配置）

如果你只是想快速用起来，**不需要装任何额外软件**——刚才你装 CC 用的那个终端，就是你跟 CC 对话的窗口。

**操作方式：**

1. 先准备一个"工作区文件夹"——在桌面右键新建一个文件夹，比如叫"CC工作区"。这个文件夹就是 CC 能看到、能改动的范围。
2. 在终端里**先切换到这个文件夹**，再启动 CC。

```bash
cd 你的工作区文件夹路径
```

> - **Mac**：右键文件夹 → 按住 Option 键 → 选"拷贝 xxx 为路径名称"

**装 Cursor：** 去 `https://cursor.com` 下载（国内可直接访问），双击安装包按提示装完。

**打开工作区：** 装完打开 Cursor，会看到这个欢迎界面：

![](/images/stage-5/cc-cursor-open-project-win.webp)

> 💡 **重要概念**：这个文件夹就是 CC 的"工作区"。**默认情况下 CC 只会在这个范围内读写，不会去碰你电脑上其他文件**——除非你明确叫它去某个具体路径，并且它会向你确认权限。但即便如此，**新手期建议把所有任务都限制在工作区里**，不要让 CC 去动桌面、文档、下载这些放着重要文件的位置，养成"专项任务建独立工作区"的习惯最稳妥。

**认识 Cursor 主界面：** 打开工作区之后长这样：

> ⚠️ 注意不要跟右边那个"Cursor 自带 AI 助手"搞混——你接下来跟 CC 对话，**都是在底部终端里**，不是右侧那个聊天框。

## 八、第五步：跑通第一个任务

好了，万事俱备，我们来让 CC 真的干点事。

**第一个任务建议挑一件这样的事**：小、能完整做完、能立刻看到结果。

下面三个都是适合的"试金石"任务，挑一个你最有兴趣的：

**选项 A：做一个个人介绍页面（HTML，最直观）**

> 不需要你懂 HTML，CC 全帮你做，你只是验证它真的能干活。

```
目标：做一个我的个人介绍单页 HTML，深色背景、卡片式布局，左边一个圆形头像占位，右边写名字、一句话简介、三条履历。

位置：就在当前目录下，文件名 index.html，样式内联进 HTML，不要外部依赖。

验证：做完之后用浏览器打开能看到完整页面，没有报错。

```

**选项 B：让 CC 帮你整理一堆文件（实用、推荐）**

> ⚠️ **重要：第一次试，不要直接拿桌面操作！** 桌面文件很多很杂，万一 CC 误操作了重要文件，恢复起来很麻烦。**先建一个测试文件夹**：
>
> 1. 在桌面新建一个文件夹，比如叫 `test-整理`
> 2. 随便从桌面/下载文件夹里复制 10–20 个文件（图片、文档、压缩包都来一点）丢进去

位置：就在当前目录操作，子文件夹不存在的话就新建。

验证：操作完之后，当前目录只剩下三个子文件夹。

约束：不要删除任何文件，只是移动；如果有重名冲突，给文件加上数字后缀，不要覆盖。

## 九、第六步：学会跟 CC 好好说话

这一节是整篇教程**最重要的部分之一**。

很多人 CC 跑起来了，但用一段时间会觉得它"越来越笨"，或者结果总是不对——根本原因往往就是：**说话方式不对。**

### 「四件套」Prompt 公式

CC 不是在跟你聊天，它是把你说的话当**工单**来执行。所以每条指令，最好按这个结构写：

| 部分 | 意思 | 例子 |
|---|---|---|
| **目标** | 你要它做什么 | "帮我写一份周报" |
| **位置** | 放在哪里、叫什么名字 | "存到当前目录下，文件名 weekly-report.md" |
| **验证** | 怎么判断它做完了 | "内容不少于 300 字，包含本周亮点和下周计划两个章节" |
| **约束** | 不能做什么 | "不要用太多专业术语，风格要口语化" |

这四项不需要每次都写得很完整，**但是少写哪一项，CC 就会自己假设那一项**——它的假设不一定和你想的一样，于是你拿到一个"不对"的结果。

**反面例子**：你说"帮我整理一下这个文件夹"。

CC 会想：整理是什么意思？按日期？按类型？放哪里？……它会自己做决定，但不一定是你要的。

**正面例子**：你说"把当前目录里所有 .jpg 文件，按文件名里的年份，分别移进 2024/、2025/、2026/ 三个子文件夹，文件夹不存在就新建"。

这样它不需要猜，直接做，结果就是你要的。

### 三种权限模式

CC 有三种工作模式，按 **Shift + Tab** 在它们之间循环切换（按一次切一个，按到你要的那个为止）：

| 模式 | 特点 | 适合场景 |
|---|---|---|
| **默认模式** | CC 自己判断哪些操作要问你 | 一般任务 |
| **计划模式（Plan Mode）** | 先给你看一份完整计划，你确认后才动手 | 重要任务、复杂任务 |
| **自动模式（Auto / Accept Edits）** | 改文件不再询问，全速跑 | 已经对齐好的任务 |

**新手强烈推荐用「计划模式」。**

按 Shift + Tab 几次，进入计划模式之后，CC 会先把它打算怎么做写出来给你看，你觉得对了再点同意让它执行。**提前花 2 分钟确认计划，比它干了一半你发现方向不对再花 30 分钟改要值得多。**

### 三个输入小技巧

**1. `@` 引用文件 —— 最常用**

在 CC 对话框里输入 `@`，会弹出一个选择列表：

> ⚠️ **注意**：必须是**英文键盘下的半角 `@`**（按 `Shift + 2` 出来的那个），中文键盘下打的"＠"（全角，更宽）CC 识别不了，不会弹出列表。如果你弹不出来，先把输入法切到英文再敲。

![](/images/stage-5/cc-at-skill-list.webp)

*输入 `@` 后弹出的列表里包含两类东西：**前面带 `+` 号的是文件**（图中 `+ index.html`）、**前面带 `*` 号的是 Skills/Agent**（后面会讲）。这一节先只看文件——选中某个文件，就把它的内容精准给到 CC*

用 `@` 直接指定文件，比你用嘴说"按照我之前的那个模板"要清晰得多。比如：

> `@模板.docx` 按照这份模板写一份给客户的方案

**2. `!` 直接执行命令**

在 CC 对话框里，以 `!` 开头，后面跟一条命令，CC 会直接帮你执行。

- `!ls`（Mac）/ `!dir`（Windows）：查看当前目录有什么
- `!open .`（Mac）/ `!explorer .`（Windows）：打开当前文件夹

这样你不用切出 CC 去另一个终端，对话框里就能搞定一切。

**3. 粘贴报错（最实用）**

任何报错——无论你在哪里看到的——选中复制，粘贴进 CC 的输入框，加一句"帮我修一下"。CC 会读懂报错、定位问题、改给你。比你自己去 Google 快很多。

## 十、第七步：防止 CC "变笨"（Context 管理）

用一段时间 CC，你可能会发现：明明刚开始用还挺好的，越用越觉得它"变笨了"，开始答非所问、犯之前没犯过的错。

这不是 CC 真的变笨了，是 **Context（上下文）满了**。

**简单解释**：CC 能"记住"的内容是有限的——每次对话、每个被 `@` 的文件、跑过的每条命令，都会占用这个"记忆容量"。容量快用完时，CC 就开始遗忘前面的内容，表现就是越来越不对劲。

**先学会看用量**

随时在 CC 输入框里敲：

```
/context
```

按回车，CC 会告诉你当前 Context 用了多少、还剩多少（一般以百分比形式显示）。**感觉 CC 反应变慢、答不准的时候，第一反应就是敲 `/context` 看一眼**——不用强迫自己定时看。

**满了怎么办（两个救命命令）**

| 用量 | 用什么命令 | 作用 |
|---|---|---|
| 50% 左右 | `/compact` | CC 把历史记录整理成摘要，腾出一些空间继续干（不会完全忘记） |
| 70% 以上 | `/clear` | 清空当前会话，从零开始（前面的事它全忘了，需要你重新说背景） |

`/compact` 运行起来是这个样子：

![](/images/stage-5/cc-compact-command.webp)

*`/compact` 执行中：CC 正在压缩会话内容。底部还提示"Double-tap ESC to rewind"——快速按两下 ESC 键，相当于"撤销"，把会话和文件回退到几步之前的状态，是你的后悔药*

**核心原则：一个任务一个会话。** 不要在一个会话里塞五件无关的事情，它会越来越乱。

**另一种推荐做法：直接新开一个终端窗口。** 比 `/clear` 更干净，原来那个窗口先放着，万一要回头查也还在。

- **Mac · 系统终端**：菜单栏点"Shell → 新建窗口"，或者按 `Command + N`
- **Mac · iTerm**：`Command + T` 开新标签页
- **Windows · 终端**：点顶部标签栏的 `+` 号，或者按 `Ctrl + Shift + T`
- **Cursor / 其他 IDE**：底部终端区域有个 `+` 号，点一下就开新的终端标签

新开的终端里 `cd` 到工作区，重新输 `claude` 启动，就是一个全新会话。

## 十一、第八步：给 CC 写「入职手册」（CLAUDE.md）

CC 每次新开会话，都会忘记你之前跟它说过的所有事。

但是！有一种方法让它每次启动都自动"记住"一些固定的事——**CLAUDE.md**。

**CLAUDE.md 是什么？**

是一个普通文本文件，放在你的"工作区"根目录里。**这里"工作区根目录"就是你之前用 Cursor 打开的那个文件夹的最外层。**

CC 每次启动，第一件事就是去工作区根目录找有没有这个文件，有就自动读进来，把里面的内容当作"这个项目的入职说明"。

**自动生成第一版**

在 CC 的输入框里输入：

```
/init
```

按回车，CC 会扫描你的工作区，自动帮你生成一份 CLAUDE.md 草稿。

**手动写也行，参考模板**

如果 `/init` 生成的不合你心意，也可以新建一个名字叫 `CLAUDE.md` 的文本文件，写入下面这种内容：

```markdown
# 这是什么文件夹
[一句话描述，比如：我用来整理读书笔记的工作文件夹]

# 一些固定规则
- 所有回答都用中文，不要用英文
- 不要修改 backup/ 子文件夹里的任何文件（那是我的备份）
- 修改任何文件之前，先把要做的事告诉我，等我同意了再动手
- 做完一件事按这个格式汇报：① 做了什么 ② 改了哪些文件 ③ 还有什么没做完

# 沟通风格
不要客套话，直接说重点。如果我说的不清楚，先反问我，不要瞎猜。
```

类比一下：**CLAUDE.md 就是"员工手册"**，你只需要写一次，CC 之后每次"上班"第一件事就是读这本手册，了解规则再干活。

## 十二、进阶：Skills

用 CC 一段时间后，你会发现有些事会反复做——每次写周报都要重新描述格式，每次整理文件都要重新说规则。

这时候就可以用到 **Skills**。

**Skills = 工作方法的封装**

把你的"标准做法"写成一个 Skill 文件，之后只要让 CC 干这件事，它就自动按你的标准方法来，不需要你每次解释。

比如，你可以写一个叫"写周报"的 Skill，里面规定：
- 用什么格式
- 必须包含哪几个章节
- 用什么口吻
- 哪些事情**不要**写进去

写好之后，下次你只要说"帮我写本周周报"，CC 会自动调用这个 Skill，按你规定的格式来。

**怎么看现有的 Skills？**

回到上一节那张 `@` 列表图——里面除了 `+ index.html` 这种带 `+` 号的文件，还有一堆带 `*` 号、带 `(agent)` / `(skill)` 这类后缀的条目。**它们都是已经为你装好的"可调用工具"，一开始不用区分是 Skill 还是 Subagent**——能调出来就能用，进阶时再细看分类。

> 💡 一开始这些可能一个都没有，这是正常的。你可以慢慢自己写，也可以从社区找现成的（搜"claude-code skills 仓库"会有很多）。

**Skills 文件放在哪？（按 Claude Code 官方约定）**

- `~/.claude/skills/<skill 名字>/SKILL.md`（Mac）/ `C:\Users\你的用户名\.claude\skills\<skill 名字>\SKILL.md`（Windows）：放这里**所有项目都能用**
- 项目的 `.claude/skills/<skill 名字>/SKILL.md`：只对这个项目有效

每个 Skill 是一个独立文件夹，里面的 `SKILL.md` 写明触发条件和执行步骤——格式有门槛，进阶之后再深入。

> 💡 顺带提一下：Claude Code 里还有一个相邻概念叫 **Subagents**（子代理），用 `/agents` 命令或 `.claude/agents/` 目录管理，跟 Skills 不是一回事。新手阶段不用分清，等你开始想"我能不能让 CC 同时干几件事"的时候，回来翻 [Anthropic 官方 Subagents 文档](https://docs.claude.com/en/docs/claude-code/sub-agents) 即可。

## 十三、急救三步：CC 卡死怎么办

用 CC 的时候总会遇到它卡住、跑偏、或者一直循环改不好的情况。遇到这种情况，记住这三步：

**第一步：按 `Ctrl + C`**

强制中断它正在跑的任何循环。Mac 上也是 `Ctrl + C`（不是 Command + C）。

**第二步：输入 `/clear`**

清空这个会话，把它"过去干的事"全部忘掉。

**第三步：重新描述任务，写得更具体**

上一次你看到它在哪里卡住了，这次把那个点说清楚，避免它再走同一条错路。

**90% 的卡死情况，这三步能解决。**

如果三步还不行，多半是任务本身超出了模型能力——拆得更小再试。

## 十五、常见问题

**Q1：安装命令跑了报错，什么都没装上？**

最常见原因：
- Mac 无翻墙路线：命令里有特殊符号被微信改成了全角字符（特别是 `@` 和 `-`），用上面代码块的"复制"按钮重新复制
- Windows 用户：`winget` 不认识？需要先把 Windows 系统更新到最新版（设置 → Windows 更新）

**Q2：装好了，输入 `claude` 说"找不到命令"？**

这是 PATH 没配好。
- Mac 用户：把终端窗口关掉，重新开一个新的；或者运行 `source ~/.zshrc`
- Windows 用户：把 PowerShell 关掉重新打开

**Q3：CC Switch 都配好了，进 CC 却显示"API 错误"？**

按顺序检查这三件事：

1. **CC Switch 里你选的那个供应商是不是显示"✓ 使用中"**？没显示就鼠标点一下让它点亮
2. **API Key 有没有填对**？特别是前后是不是有多余的空格
3. **是不是先开了 CC 才去 CC Switch 切换的**？切换必须在 CC **没启动**的时候做，已经在 CC 里就先 `/exit`

**Q4：CC 启动正常，但回答总是英文，怎么改成中文？**

最简单：在你工作区根目录的 CLAUDE.md 里加一行：

```
所有输出和回答，请统一使用中文。
```

或者每次对话开头说一句"请用中文回答我"，但每次都要说，不如写进 CLAUDE.md 一劳永逸。

**Q5：用了国产模型，感觉比 Claude 官方差很多，怎么办？**

先看清差距到底有多大。CC 框架再好，模型能力是有上限的——但 2026 年下半年，这个上限已经抬高了不少：**DeepSeek V4 Pro、GLM-5.3、Kimi K3 这一档在编程类、日常文本任务上已经很能打**，Kimi K3 还在编程盲测榜上排过第一。真正还剩明显差距的，是复杂推理、长篇创意写作这类活，对照组是 Claude 官方最强的 Fable 5。具体型号名以你充值/配置时各平台公布的为准（这些平台模型名迭代很快）。

两个建议：
- 接受这个差距，国产模型省心 + 便宜 + 不用翻墙，对日常 80% 的任务够用
- 重要任务（比如做关键决策、需要深度推理）的时候，临时切到 Claude 官方账号用一下（注意第三章讲的封号风险，账号和支付环境要干净）

**Q6：我电脑很旧，跑 CC 会不会很慢？**

CC 本身非常轻，绝大部分计算发生在云端（模型那边），你的电脑只是负责发送指令和显示结果。硬件要求很低，关键看系统版本——按官方要求：**macOS 13.0 (Ventura) 及以上 / Windows 10 1809 及以上（或 Windows 11）**。如果你的系统比这老，先升级一下再装。

实际感受到的"慢"通常来自两个地方：网络慢（请求大模型要往返云端）、模型响应慢（复杂任务模型本身就要想几十秒）。这跟电脑配置无关。

**Q7：CC 改坏了我的文件怎么办？**

第一时间双击 ESC（按两下），CC 有"回滚"功能可以把文件恢复到几步前的状态。

防患于未然：重要文件先备份，或者把工作区文件夹整体放进一个 Git 仓库（这样所有改动都有版本可查），等以后熟悉了再做。

## 十六、下一步去哪

装好 CC 只是开始。CC 真正的价值，是在你把它用进自己日常工作流之后才会显现。

几个值得接着探索的方向：

- **写自己的 Skills**：把最常做的事情封装成 Skill，叫一声就执行，省下重复描述的时间
- **MCP 扩展**：给 CC 接上各种工具（操控浏览器、访问数据库、查日历、发邮件……）让它真的能"帮你做事"
- **多 Agent 分工**：大任务拆成几块，多个 CC 并行干，效率翻倍
