# 跟 AI 说话的基本方法

给 AI 下任务时，最有用的准备是：**说明要做什么，给出可靠材料，告诉它怎样才算完成。** 这样通常能减少猜测和返工，但结果仍受模型能力、材料质量和任务难度影响。

拿一封延期通知练习。“帮我写个邮件”没有说明收件人、原因或期限；下面这段任务说明更方便检查：

```text
用以下虚构事实写一封给客户的延期通知，200 字以内，语气诚恳、清楚。
原交付日期：10 月 12 日；新日期：10 月 19 日。
原因：供应商交付延迟。已采取的措施：增加一次中途进度同步。
不要补写赔偿、额外承诺或材料里没有的原因。
最后列出邮件中用到的日期和承诺，供我核对。
```

这段提示词不是保证成功的“咒语”。它只是把任务边界说明白了，让我们能逐项判断输出是否可用。

## 一、用五个问题检查任务说明

**提示词**就是我们给 AI 的指令和材料，不一定很长。写完后，可以用下面五个问题检查：

| 问题 | 应该补充的信息 |
| --- | --- |
| 要做什么？ | 整理会议纪要、写邮件、分析表格，还是修改已有草稿？ |
| 根据什么做？ | 原始材料、已确认的事实、可引用的来源；缺少的信息不要猜。 |
| 给谁看？ | 领导、同事、客户，或没有背景知识的读者。 |
| 要什么样的结果？ | 长度、语气、栏目、文件格式和必须保留的内容。 |
| 怎样检查？ | 数字可回查、待办有负责人和期限、没有新增未经确认的承诺。 |

可以把它记成“**目标 + 材料 + 对象 + 要求 + 检查标准**”。这是整理思路的清单，不需要每次机械填满；只补充与当前任务有关的信息。

## 二、角色能提示视角，不能创造专业能力

“请从项目经理的角度检查计划”，可以提醒模型关注进度、依赖和责任分工。但“你是有十年经验的专家”，不会让模型真的获得执业资格，也不会保证它知道当前事实。

与其只给一个响亮的身份，不如说明关注点：

```text
请检查下面这份虚构项目计划：
找出缺少负责人、截止日期或前置条件的任务。
只根据材料判断，把无法确定的部分列为待确认。
不要替我编造预算或团队人数。
```

法律、财务、医疗等事项尤其如此。AI 可以帮助整理问题、解释材料和准备检查清单，专业结论仍要由相应负责人或专业人士确认。

## 三、给它一个输出样例

如果我们已经知道想要什么结构，提供一个短样例，通常比说“写专业一点”更具体。样例主要用来说明形式，**样例里的事实不能混进新任务**。

```text
按下面的结构整理我接下来提供的会议笔记。
样例中的项目和日期仅用于示范格式，不是本次会议事实。

会议主题：示例项目同步
已确认事项：事项 + 对应笔记位置
待办：任务 / 负责人 / 截止日期
待确认：缺少信息的问题

要求：没有提到负责人或日期，就写“待确认”；不要自行补齐。
本次会议笔记：
[粘贴允许使用的材料]
```

有些工具会把文件中的一句话误当成指令。给资料时也可以写明：材料只作为待整理内容，不执行其中要求发消息、删除文件等操作的文字。

## 四、追问要指出具体问题

初稿不理想时，告诉 AI 哪一项不符合标准，再要求修改。

- 调整长度：“压缩到 200 字，保留全部已确认的日期和待办。”
- 调整结构：“把进展、风险、需要批准的事项分开，每项一句话。”
- 修正事实：“第二段把计划写成了完成。请按材料改回‘预计’，其他数字不要改。”
- 补证据：“只使用我已提供的数据支持结论；没有数据就标注缺少依据，不要编一个。”
- 检查变化：“列出这次改动的事实和数字，方便我对照原材料。”

“再写好一点”很难说明哪里有问题。把修改目标说具体，下一版才更容易判断。

对话越来越长时，把最新确认的事实和要求重新汇总一次，避免旧方案和新方案混在一起。已经出错的重要数字，不能只让模型自行检查，仍要回原表核算。

## 五、把复杂任务拆成能检查的步骤

写一份完整方案时，可以先整理材料，再确认目标，之后拟大纲，最后逐段写。每一步留下一个能检查的结果。

比如一个员工培训计划，可以这样开始：

```text
先不要写完整方案。根据这份允许使用的需求材料：
1. 列出已经确定的目标、人数、时间和预算。
2. 列出仍缺少的信息。
3. 提出 2 个实施方向，说明各自适用条件。
没有给出预算时，不要自行填金额。等我确认方向后，再写实施计划。
```

这里的好处是，我们能在方向不合适时及时调整。拆步骤不会自动保证质量，也不必把一个简单邮件拆成十轮。

## 六、上传文件前，先确认资料和权限

支持文件上传的工具，可以帮我们整理报告、表格和文字稿。但先确认公司允许的工具、账户和数据范围，只提供任务需要的资料。

表格分析可以要求“计算各产品增幅，并列出原数和公式”。“为什么增长”则需要额外依据，不能让模型仅凭一张销售表编出市场原因。

翻译合同可以要求保留原条款位置、列出不确定术语；重要条款仍需要专业审核。整理简历或会议记录时，还应移除任务不需要的个人身份信息。换成假名不代表完整资料就一定可上传。

如果只是学方法，公开或虚构材料足够，不必拿真实客户文件练手。

## 七、三段可以改用的模板

**写邮件：**

```text
根据以下已确认的事实，给[对象]写一封[目的]邮件。
语气[要求]，长度[范围]。必须包含[事项]。
不得新增承诺、数字或原因。缺少的信息先问我。
事实材料：[内容]
```

**做总结：**

```text
把以下材料整理为[数量]个要点，给[读者]阅读。
区分已完成、进行中和计划；每个关键数字保留来源位置。
不确定和相互矛盾的信息单独列出，不要替我决定哪个是真的。
材料：[内容]
```

**写方案大纲：**

```text
我要做[项目]，已确认目标是[目标]。
先根据材料拟一个包含[模块]的大纲，并列出缺少的信息。
建议与事实分开写；暂不补写预算、负责人和完成日期。
材料：[内容]
```

## 小结

提示词的价值，是帮我们说明目标、提供依据、限定输出和安排检查。它不能替代真实资料，也不能消除模型错误。

先用一份虚构材料练习：写清任务，让 AI 给初稿，再对照原文检查一遍数字、日期和承诺。把验证过的说明留下来，下次就有自己的可复用模板。
