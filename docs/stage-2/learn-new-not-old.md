# 学新不学旧，用实不用虚

学习 AI，可以先记住两个原则：**操作步骤要跟上当前工具，选择工具要围绕真实需求。** 不需要追完每一次发布，也不需要先买齐订阅才能开始。

比如我们想整理一份周报。先拿虚构材料，让已有、允许使用的工具整理进展和待办；核对后看它有没有节省整理时间，再决定要不要换工具。这比看完“最强模型”的介绍就付费，更容易判断是否值得。

## 一、“学新”是更新操作，不是丢掉方法

AI 工具的按钮、功能入口、套餐和文件处理能力变化很快。一篇旧教程里的安装步骤，可能已经不适用于现在的版本。照着操作前，先看教程日期、自己使用的版本和当前官方说明。

但有些方法能长期用：把目标说清楚、提供可靠材料、给出输出样式、检查数字、把复杂任务拆成能验收的小步骤。**这些方法不会因为换了模型就自动失效。**

因此，遇到新消息时可以问：它是否解决了我正在遇到的问题？如果只是名字更新，而我们手头的任务已经能做好，了解一下即可，不必重新学一遍整套工具。

## 二、先判断是否需要搭建复杂工具

有些工具可以让模型操作电脑、调用其他软件或定时执行任务。搭建它们通常还涉及权限、账号、费用和后续维护。

如果需求只是改写一段文字或整理一份材料，一个普通对话工具可能已经够用。如果要反复处理一批文件、跨软件协作，或者执行固定流程，才有必要进一步比较能动手执行的工具。

本地安装和云端服务也有实际差异：资料在哪里处理、能读取哪些文件、谁维护环境、如何计费，都要看具体方案。不能仅凭“本地”或“云端”判断哪个更省钱或更安全。

我自己就有过因为不了解调用用量，一上午消耗几十美元的经历。值得吸取的教训是：**试用前了解计费方式，限定材料和执行范围，先做一个小样本。** 费用上限不清楚时，不要开启长时间自动运行。

## 三、模型能力和提示词都影响结果

模型能力提升后，有些任务不再需要很复杂的措辞。我们不必把大量时间花在搜集“神奇提示词”上。

但这不意味着提示词不重要。模型不知道我们的真实目标、公司口径、已确认的数字和交付格式，仍需要我们提供这些信息。

比如“做一张海报”容易得到一个通用作品；“做一张部门读书会海报，标题用这句话，时间地点按这份材料，留出二维码位置”，才说明了工作需要。措辞可以简单，**任务和材料不能含糊**。

保存自己验证过的任务说明、例子和检查清单，通常比收藏一大堆从未试过的提示词更有用。换工具时，用同一份材料再试一次，就能看出哪些约束仍然有效。

## 四、“用实”是先做成一件具体的事

看到教程推荐某个工具，我们很容易先开订阅，再想它能帮自己做什么。如果没有明确任务，再强的工具也可能闲置。

可以按这个顺序开始：

1. **挑任务**：这周要写一封邮件、整理一次会议，还是做一份汇报？先选一件。
2. **定标准**：什么叫完成？例如待办要有负责人和期限，报告里的数字能回到原表。
3. **用已有工具试**：先选公司允许使用、我们已经能访问的工具，用公开或虚构材料试做。
4. **记录效果和成本**：哪些地方能直接用，哪些地方要重做？人工检查和修改也算进总时间。
5. **再考虑升级**：当前工具确实卡住任务，而且新工具能解决具体问题，再决定付费或学习。

一次效果不错，不代表所有工作都适合交给它。也不要用“达到 80 分”这样的感觉代替验收：一份外观漂亮但金额错误的报告，仍然不能交付。

## 小结

“学新不学旧”，是让操作步骤适应当前版本，同时保留已经验证的方法；“用实不用虚”，是先有任务和标准，再选工具。

我们可以从一件小事开始：把材料整理清楚，让 AI 做初稿，自己查事实、改表达。做成之后留下可复用的模板，下次就能少走一遍弯路。
