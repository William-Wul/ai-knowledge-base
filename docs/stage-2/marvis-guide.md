# 智能体/助理类 AI：从 Marvis 开始

> 国内直接用 · 微信/QQ 扫码登录 · 免费额度管够 · 从"问 AI"到"让 AI 去办"

**智能体（Agent）是接到任务后自己拆步骤、自己动手、干完活再来交差的 AI。** 它和我们前面学的聊天 AI（豆包这类）用的是同一类大模型，区别在于：聊天 AI 只负责"说"，智能体能"做"。

这篇教你上手第一个智能体：腾讯的 **Marvis（马维斯）**，一个装在电脑上、替你管电脑的 AI 管家。读完这篇，你能做到六件事：

1. 搞清楚"智能体"是什么，它和聊天 AI 差在哪
2. 在自己电脑上装好 Marvis，微信/QQ 扫码登录
3. 跑通第一个任务（电脑体检），亲眼看它替你干活
4. 学会日常派活：清理电脑、整理文件、改系统设置、跨软件收资料
5. 用上三个进阶入口：自动任务、技能广场、本地知识库
6. 在手机上遥控自己的电脑，出门在外也能取文件、派任务

文章比较长，不用一口气读完，照着目录跳到需要的那节跟着做就行。

还有一点要说清：**智能体不是更聪明的模型，而是让模型能动手的产品形态。** 同一个大模型，装进聊天框里就只能陪你说话；给它接上操作电脑、读文件、开软件的权限，它就成了智能体。所以判断一个工具是不是智能体，看的不是它多聪明，而是它能不能替你把活干完。

你可能会问：智能体工具不是 Coze、秒哒这些吗？那些是"搭建平台"，给想自己动手做一个智能体的人用的，要配置流程、连接口，对零基础的人不友好。现在更省事的路径是**直接用一个现成的智能体**，先体验"AI 替我干活"是什么感觉，以后有需要再去研究怎么搭。

## 二、Marvis 是什么，为什么从它开始

**Marvis 是腾讯 2026 年 5 月底发布的电脑 AI 管家，官方对它的定位是"操作系统层级的个人 AI 助手"。** 这个拗口的说法翻译过来就是：它不是一个只活在自己窗口里的软件，而是能调动你整台电脑的助手，文件、系统设置、其他软件、浏览器，它都够得着。

名字也有来头：Marvis 取自 **Make Your Jarvis**。贾维斯（Jarvis）是《钢铁侠》电影里那个无所不能的 AI 管家，主角一句话，它把事办了。Marvis 想做的就是给每个人配一个这样的管家。

- **免费额度管够**：目前每天有 1000 万 Token 的免费额度。Token 是 AI 计算工作量的单位，可以粗略理解成"AI 读写的字数"，一个汉字大约折算一两个 Token。1000 万是什么概念？重度用一整天也很难碰到上限，日常使用基本等于不限量。

## 五、它是怎么干活的：一个主管带五个专员

**Marvis 不是一个 AI 单打独斗，而是一个主管带五个专员的小团队。** 你把任务交给主管（主 Agent），它负责理解需求、拆解任务、调度协作，再分派给对应的专员：

![Marvis 的六个 Agent 分工：主 Agent 负责理解需求拆解任务，Search、Computer、Browser、File、App 五个 Agent 各管搜索、系统、网页、文件、应用](/images/stage-2/2026-07-03/marvis-agents.png)

<div class="figcaption">官方给出的团队分工：主 Agent 当主管，五个子 Agent 各管一摊。（图源：<a href="https://marvis.qq.com/" target="_blank" rel="noopener">Marvis 官方</a>）</div>

五个专员各自的地盘：

- **Search Agent**：上网搜索、聚合信息，还会带上关键引用。
- **Computer Agent**：管系统，改设置、检测硬件、清理优化。
- **Browser Agent**：操作网页，点击、抓数据、填表单。
- **File Agent**：管文件，搜索、阅读、编辑、格式转换。
- **App Agent**：调用和操作电脑上装的软件。

这是现在智能体产品的常见做法：把大任务拆给各有专长的"子智能体"，比让一个 AI 什么都干更靠谱。不过别被"六个 AI"唬住，**对我们来说入口永远只有那一个输入框**，分工是它内部的事。派活之后你能在对话里看到它怎么调度：主管接单、派给谁、谁干完了回报，全程有记录，就像看一个小团队在你眼前跑任务。

<div class="figcaption">派活后的对话界面：主 Agent 把扫描任务派给 File Agent，干完回报，再由主 Agent 汇总写报告。（图源：Marvis 产品界面）</div>

## 六、第一个任务：给电脑做个体检

**建议把"电脑体检"当第一个任务：零风险、几分钟出结果，还能直观看到它真的在操作你的电脑。** 最简单的派法，在输入框里说一句：

```
给我的电脑做一次全面体检
```

想要更彻底的体检，可以把要求写细。下面这条是实测好用的完整版，直接复制去用：

```
给电脑做一次全方位体检，从磁盘、性能、电池到使用习惯一次扫清，
按下述要求执行，各项任务并行，不要重复扫描：
（1）扫描磁盘空间和可清理的垃圾文件（系统临时文件、浏览器缓存、
回收站、休眠文件、应用日志），统计每项占用空间和预计可释放空间。
（2）扫描下载、桌面、文档、视频文件夹中超过 60 天未修改的大文件
（>1GB），列出前 5 个的路径、大小和最后访问时间。
（3）检查系统性能：内存使用率、CPU 占用、自启动项数量和清单、
后台进程数量，标注建议禁用的自启动项。
（4）检查电池健康（笔记本）：健康度百分比、循环次数、电源计划。
（5）分析使用习惯：近 7 天日均开机时长、是否长期插电使用等。
（6）以网页形式生成电脑体检报告，给出综合建议。
```

顺便说一下这条指令好在哪：它把"体检"这个模糊要求拆成了六件具体的事，每件都说清了查什么、怎么呈现。**任务越具体，智能体干得越好**，这条规律对所有 AI 都成立。

派出去等几分钟，它会交回一份速览报告：电池健康、CPU、内存占用、可清理的垃圾、闲置大文件、后台进程、开机自启动项，每项都有结果和评级，还会用网页形式生成一份排版舒服的完整报告。

![Marvis 电脑体检速览：电池健康、CPU、内存、可清理垃圾、闲置大文件、后台进程、自启动项七个维度的结果和评级](/images/stage-2/2026-07-03/marvis-checkup.png)

<div class="figcaption">体检报告示例：哪里该清、哪里正常，一张表看完；下方还会附上完整的网页版报告。（图源：Marvis 产品界面）</div>

**体检完别停，顺手让它把建议执行了。** 比如报告说某个软件的自启动项建议禁用，你回一句"把它禁了"，它直接调系统权限办好，连弹窗都不用你点。这一步做完，你对"智能体"三个字的理解就落地了：它不是给你一份《优化建议清单》，而是把优化做完。

## 七、日常派活清单

体检跑通了，下面这些活都是它的拿手项，每个都附了能直接抄的指令。

### 1. 清理大文件和缓存

```
找出电脑里超过 1GB、超过 60 天没动过的闲置文件，列出来给我看
```

它会把陈年老文件、软件缓存、虚拟机镜像这类占地大户翻出来，逐项列给你决定去留。有人靠几轮对话清出了 100GB 的空间。连微信的聊天文件它都能按时间线梳理，帮你判断哪个时间段之前的可以清。

### 2. 整理桌面和文件夹

```
把电脑桌面上的文件整理一下，按类型归类
```

散落一屏的文件、图片、压缩包，它会分门别类收进文件夹，原有的子目录也会保留。桌面这东西今天整理完明天又乱？往下看第八节的"自动任务"，让它每天早上自动整一遍。

### 3. 一句话改系统设置

```
修改屏幕息屏时间为 10 分钟
```

Windows 的设置散落在"设置"和"控制面板"两个地方，找起来费劲；Mac 的设置项也藏得深。Marvis 的做法是**直接把设置改好，或者把对应的设置面板打开摆到你面前**，而不是回你一段"请点开设置，然后……"的文字指引。这是它和聊天 AI 差别最明显的地方，也是它比大多数同类智能体做得细的地方。

![Marvis 执行系统设置任务：主 Agent 派活给 Computer Agent，完成后列出已完成的操作，并附上系统设置面板的快捷打开入口](/images/stage-2/2026-07-03/marvis-system-setting.png)

<div class="figcaption">让它改一个系统开关：派给管系统的专员直接办好，还附上设置面板的快捷入口，点一下就跳过去。（图源：Marvis 产品界面）</div>

### 4. 跨软件、跨网页收资料

```
帮我在公开网页中收集某某领域排名前十的产品信息，整理成表格，
字段包括：名称、开发者/公司、定位、核心功能、适合人群
```

这种活要同时开十几个网页、复制、粘贴、对齐字段，人干半天，它自己调度搜索和浏览器的专员就干了。同理，"把我最近一个季度的发票找出来整理成 Excel"这种要翻好几个软件的活也是它的菜。

### 5. 让它认识你这个人

有一个流传很广的指令玩法，用来让智能体快速了解你：

```
你全面扫描一下我电脑里面的资料，然后告诉我值得做的 10 件事情，
以及分析一下我是一个什么样的人
```

它会把你电脑里的文件通读一遍，然后给你一份分析报告：你在忙什么、哪些事值得做、你是个什么样的人。实测效果出人意料地准，能从文件痕迹里看出你的职业、习惯甚至性格。

![Marvis 扫描电脑后生成的分析报告片段：根据电脑里的文件给出"将内容创作流程产品化""建立个人知识管理体系"等具体建议](/images/stage-2/2026-07-03/marvis-analysis-report.png)

<div class="figcaption">扫描分析报告的片段：根据电脑里的实际文件给出的针对性建议，不是空话。（图源：Marvis 产品界面）</div>

这个玩法的实际价值是：它认识你之后，你以后派活就不用每次交代背景了。当然，"扫描我全部资料"这个动作牵涉隐私，放心，第十节有交代：扫描是在你自己电脑上完成的，不上传。

### 派活的一个窍门

**一次派一个小活，做完验收，再派下一个。** 别一上来就丢一个"帮我把电脑彻底整理好"的大任务。任务越具体、边界越清楚，它干得越好；你验收得越勤，翻车的代价越小。

---

## 八、三个进阶入口：自动任务、技能广场、本地知识库

基础派活顺手了，左侧栏这三个入口能让它的能力再上一档。

### 自动任务：定时替你干活

点左侧栏"自动任务"，把一件活设置成定期执行。两个例子：

- **每天早上整理桌面**：把第七节那条整理指令设成每天早上执行，以后每天打开电脑桌面都是齐的。
- **每天推荐一本书**：比如"每天推荐一本商业经典，输出作者背景、核心思想、3 个最重要观点、普通人如何应用、5 分钟阅读版"。设好后它每天自动交作业。

适合一切"重复、有固定套路"的活：日报、盯信息、定期清理。设置时可以选"立即执行"先跑一遍看看效果，满意再让它按时跑。

### 技能广场：给它加装能力包

**技能（Skill）是别人替 AI 写好的"某类活的成熟做法"**，比如做海报的技能、处理文档的技能。装上对应技能，它干那类活就更有章法。技能广场像个应用商店，按需挑着装就行，不用囤。

### 本地知识库：让它认识你的电脑

**本地知识库是 Marvis 最有特色的功能：授权之后，它会把你电脑里的应用、文档、图片扫描一遍并自动归类。** 左侧栏四个子项：

- **应用**：电脑上装的软件一目了然，自动分类。
- **文档**：按合同、课件、报告等类型自动归档。
- **图库**：照片按人像、地点、主题自动整理，类似手机相册的智能分类。
- **此电脑**：本地磁盘映射，当资源管理器用。

它带来的实际变化是：**电脑从"你得记住文件放在哪"，变成"你描述想找什么"。** "上个月签的那份合同""去年去海边拍的照片"，说人话就能找到。

说句实在的，单看这个界面，它现在更像一个聪明点的文件浏览器，谈不上惊艳。但它是后面很多能力的地基：第七节的找文件、第九节的手机远程取文件，都靠它对你电脑的了解。**授权前想清楚扫描范围**，这个也放到第十节说。

---

## 九、手机遥控电脑

**Marvis 有一个同类产品少见的能力：用手机完整接管你的电脑。** 不是"给电脑发个消息"那种伪遥控，是能看到电脑屏幕实时画面、能动键盘鼠标的真遥控。

### 怎么连

1. 手机上装 Marvis App（安卓、iPhone 都有），登录**和电脑端同一个账号**。
2. 电脑端点左下角"登录与设置 → 连接手机"，按提示配对。
3. 连好后，手机 App 里就能看到你的电脑设备，点进去即可。

![Marvis 设置菜单：包含设置、AI 模式（效率模式）、连接手机（未连接）、意见反馈、立即登录几项](/images/stage-2/2026-07-03/marvis-settings.png)

<div class="figcaption">"连接手机"和"AI 模式"都在左下角登录与设置的菜单里。（图源：Marvis 产品界面）</div>

另外它还支持绑定微信，绑定后直接在微信里发消息给电脑派活，连 App 都不用打开。一部手机还能同时连**多台**电脑。

### 能干什么

**远程取文件。** 最刚需的场景：人在外面，文件在家里或办公室电脑上。在手机上说一句：

```
帮我在电脑里找那份季度汇报文档，发到手机上
```

不用记得文件在哪个盘哪个文件夹，管文件的专员自己去翻，OneDrive、iCloud、本地下载目录都能搜到，找到后直接传到你手机上。

**远程派活。** 手机上能看到电脑端的全部对话和任务进度，也能直接发新任务让电脑去干。下班路上先派活，到家活已经干完了，比如让家里电脑提前把要看的电影下载好。

**实时接管屏幕。** 点进设备后能看到电脑桌面的实时画面，支持触屏操作、虚拟键盘和鼠标，还能一键锁屏、开防窥模式。你可以一边在手机上发指令，一边亲眼看着电脑上的操作在执行，不是盲发。

**帮长辈修电脑。** 一个特别实在的用法：在爸妈电脑上也装一个 Marvis、登你的账号（手机端支持连多台电脑）。他们电脑弹广告了、软件不会装了，你不用再在电话里比划"你点左下角那个圈"，直接手机接管他们的桌面，扫一眼就知道问题在哪，顺手就修了。相当于给全家配了个 IT 运维。

## 十、隐私和安全：讲清楚再用

让 AI 扫描整台电脑，换谁都要先问一句：**我的文件是不是都传给腾讯了？** 这事它设计得比较周到，分三层说：

**第一层：文件扫描在你自己电脑上完成。** 下载 Marvis 时会连带装几个能在本地运行的小模型，本地知识库的文件识别、分类就是这些端侧模型在你电脑里干的，**不是把文件送到云端去扫**。

**第二层：云端不留档。** 需要大模型深度处理的任务才会调用云端，官方说法是云端不保存用户信息，单次对话结束后即删除。

**第三层：有一个彻底断网的选项。** 设置里的"AI 模式"提供两档：

- **效率模式（默认）**：端云协同，简单任务在本地完成（不消耗云端额度），复杂任务才调云端。可以理解成**本地干粗活，云端干精活**。
- **本地模式**：所有计算完全在你自己电脑上跑，断网都能用，数据一步不出门。代价是硬件门槛高，显卡显存要 16GB 以上，普通笔记本开不了。特别在意隐私、或者处理敏感内容多的人可以考虑；普通用户用默认的效率模式就好。

操作安全上，**删除这类敏感动作必须经你逐项确认**。就算你给了它全部权限，它要删文件时仍会把清单列出来，你逐项勾选确认后才动手，删掉的也是进回收站可以找回。

![Marvis 删除文件前的确认界面：列出每个待删除文件的名称和路径，用户逐项勾选确认后才执行，删除后可在回收站找回](/images/stage-2/2026-07-03/marvis-delete-confirm.png)

<div class="figcaption">删除前逐项确认、删除后可从回收站找回：权限给得高，但动手的边界它守得住。（图源：Marvis 产品界面）</div>

最后给两条使用建议：一是**给本地知识库授权前，先想清楚这台电脑上有没有不该被扫描的内容**，比如存在个人电脑上的公司敏感资料；二是确认删除清单时逐条看一遍再勾，别习惯性全选。"不把敏感内容交给 AI"这条原则在智能体上同样适用，而且因为它能动手，更要当回事。

## 十一、它现在做不好什么

说清楚局限，你的预期才准：

- **创作设计类的活不行。** 让它用技能画海报，出来的效果比专门的生图工具差不少。画图、做视频这类活还是交给豆包、即梦这些专门的工具。
- **办公产出不是它的主场。** 它内置的是混元、DeepSeek 这些国产模型，临时让它做个 PPT，能给出结构完整、排版像样的七八十分交付物，应急够用；但正经的文档、表格、PPT 产出，还是办公向的 AI 工具干得更专业。
- **新产品，会犯错。** 复杂任务偶尔跑偏、偶尔干一半，所以才反复强调小步派活、每步验收。

但在"管电脑"这个主场（清理、体检、找文件、调设置、远程接管），它已经稳稳够用。作为你的第一个智能体，它最大的价值是让你用最低的成本体会到那个转变：**从"问 AI 该怎么办"，到"让 AI 去办"。** 这个感觉找到了，以后上手更复杂的 AI 工具，你都会顺得多。
