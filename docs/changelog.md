## 2026-06-12

### 界面改版

- 文章页启用全新阅读布局：删除顶部导航栏，导航统一收进左侧边栏，页面只保留"左侧导航、中间正文、右侧本页目录"三列，正文阅读区加宽至每行约 45 字。
- 新增侧边栏折叠：侧栏顶部提供折叠、沉浸阅读、搜索三个功能按钮；收起侧栏后，左上角保留同样的三个按钮，折叠状态下次访问仍然记得。
- 新增沉浸阅读模式：一键隐藏所有栏目，全屏只留正文居中显示，适合长教程的专注阅读；按 Esc 键或原位置的按钮即可退出，进入和退出的按钮位置完全一致。
- 全站启用新 logo：三档绿色"书脊"标记，寓意知识库中排列的书；浏览器标签页图标、苹果设备图标、微信分享卡片图同步更新。
- 侧边栏排版统一：分组标题不再折行，所有顶层条目统一字号、字重和颜色；侧栏滚动条默认隐藏、悬停时才显现，减少阅读时的视觉干扰。
