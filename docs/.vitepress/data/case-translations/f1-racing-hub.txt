# 精确复刻这个页面 — Lewis Hamilton / Silverstone F1 首屏

## 技术栈
- React + TypeScript + Vite
- Tailwind CSS（配置扩展 `fontFamily.sans` = `['"Albert Sans"', 'sans-serif']`，以及自定义 `f1.dark = rgb(41,41,41)` 和 `f1.yellow = rgb(237,180,11)`）
- 使用 lucide-react 图标（用到 X、Menu）
- Google Font：**Albert Sans**，字重 300;400;500;600;700;800，在 index.html 中通过 `https://fonts.googleapis.com/css2?family=Albert+Sans:wght@300;400;500;600;700;800&display=swap` 加载
- 页面背景：`#0a0e1c`，文字抗锯齿

## 整体布局
全屏首屏区域（`relative w-full overflow-hidden font-sans`），先放页面背景图与深色遮罩，再提供两种响应式布局。

**页面背景图（页面与手机内部屏幕都使用这张图）：**
```
https://images.higgs.ai/?default=1&output=webp&url=https%3A%2F%2Fd8j0ntlcm91z4.cloudfront.net%2Fuser_38xzZboKViGWJOttwIXH07lWA1P%2Fhf_20260709_152331_bd312d1a-1f20-46b9-9b68-12bcdcf6d53e.png&w=1280&q=85
```
- 页面：`<img>` 使用 absolute inset-0 w-full h-full object-cover z-0，再覆盖 `<div className="absolute inset-0 bg-black/70 z-[1]" />`

**电脑端（md+）：** `hidden md:flex relative z-[2] w-full h-screen items-center justify-center py-6` → 内部为 `items-end justify-center gap-[2vw]` 的横向布局，放三台手机模型，每台外包 `animate-fade-slide-up`，延迟分别为 300/500/700。中间手机添加 `-mb-6`。

**手机端（低于 md）：** `md:hidden relative z-[2] flex flex-col items-center gap-[50px] py-[20px] px-[20px]` → 纵向放同样三台手机，延迟为 300/500/700。

## PhoneMockup 组件
可复用的 iPhone 风格外框：
- 外层：`flex flex-col items-center`
- 外框：`relative rounded-[clamp(30px,4vw,54px)] bg-black p-[clamp(6px,1vw,12px)] shadow-2xl shadow-black/60`；内部描边为 `absolute inset-0 rounded-[clamp(30px,4vw,54px)] ring-1 ring-white/15`
- 屏幕：`relative w-full h-full rounded-[clamp(24px,3.2vw,44px)] overflow-hidden bg-[#0a0e1c]`
- 顶部灵动岛开孔：`absolute top-[3%] left-1/2 -translate-x-1/2 w-[30%] h-[4%] bg-black rounded-full z-50`
- 内容缩放：内部 div 尺寸为 `390px × contentH`（通过 ResizeObserver 测量 contentH），按 `scale = screenW / 390` 缩放，transform-origin 设为 top-left
- 侧边按钮（neutral-700）：左侧三个，位于顶部 19%/26%/35.5%（高度 4.5%/7.3%/7.3%）；右侧一个，位于 30.8%，高度 11.4%

**手机外框尺寸（CSS）：**
- `.phone-frame { aspect-ratio: 390/844; width: clamp(200px, 75vw, 340px); }`
- `@media (min-width:768px) { width: min(25vw, 42vh); }`
- `@media (min-width:1280px) { width: min(28vw, 48vh, 430px); }`

## 动画（CSS 关键帧，全部使用 `both` 填充模式）
- **fadeSlideUp**：opacity 0→1，translateY 30px→0，0.9s cubic-bezier(0.16,1,0.3,1)
- **fadeSlideDown**：translateY -20px→0，0.7s
- **fadeSlideLeft**：translateX 40px→0，0.9s
- **fadeSlideRight**：translateX -40px→0，0.9s
- **scaleIn**：opacity 0→1，scale 0.92→1，1s
- **fadeIn**：opacity 0→1，0.8s ease-out
- **speedReveal**（姓名出现）：0% opacity 0 translateX(-100%) skewX(-8deg) blur(8px) → 60% opacity 1 translateX(4%) skewX(-2deg) blur(0) → 100% translateX(0) skewX(0) blur(0)，0.8s
- **raceLineLeft**：从左侧 scaleX 0→1.1→1
- 延迟工具类：delay-100 至 delay-1600（每档 0.1s）

- 大号展示数字：110–120px，lineHeight 0.72–0.79
- 标签：text-white/60，13–16px，font-normal
